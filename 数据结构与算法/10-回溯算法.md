# 回溯算法
> [代码随想录](https://www.programmercarl.com/%E5%9B%9E%E6%BA%AF%E7%AE%97%E6%B3%95%E7%90%86%E8%AE%BA%E5%9F%BA%E7%A1%80.html#%E9%A2%98%E7%9B%AE%E5%88%86%E7%B1%BB)

## 基础
- 回溯是递归的副产品，只要有递归就会有回溯。因此，一般来说回溯函数就是递归函数，它俩指的是同一个东西。
- 回溯法的效率：回溯法并不是高效的算法，因为**回溯的本质是穷举**，穷举所有可能，然后选出想要的答案。**如果想要回溯算法高效一些，可以加一些剪枝操作**，但也改变不了回溯法就是穷举的本质。
- for 循环横向遍历，递归纵向遍历，回溯不断调整结果集
- 回溯法解决的问题：
  - 组合问题：N 个数里面按一定规则找出 K 个数的集合
  - 切割问题：一个字符串按一定规则有几种切割方式
  - 子集问题：一个 N 个数的集合里有多少符合条件的子集
  - 排列问题：N 个数按一定规则全排列，有几种排列方式
  - 棋盘问题：N 皇后，解数独等等

## 问题总结
- 关于 `startIndex`：在回溯问题中通过 `startIndex` 来控制横向遍历 `for` 循环的起始位置，有去重的作用。**对于组合问题，如果是一个集合来求组合的话，就需要 `startIndex`**，如果是多个集合取组合，各个集合之间互不影响，那么就不用 `startIndex`（eg. 电话号码的字母组合）。
- 关于集合元素存在重复的情况下的去重：`startIndex` 去除集合无重复元素下的重复结果，当集合中存在重复元素时，需要考虑：**数层去重，树枝无序去重**。数层对应横向遍历，树枝对应深度递归，可以通过使用 `used` 数组进行标记已经使用过的元素，也可以通过判断 `i > startIndex && nums[i] == nums[i- 1]` 来跳过当前横向遍历的元素。两者的本质都是跳过对同层相同元素的遍历，从而完成去重工作（**都需要排序原集合**）。同样的，还是树层去重的问题，在子集问题的求递增子序列问题中，也使用 `used` （*set类型、数组均可*）来标记使用过的元素，以排除在同一父节点下遍历到相同的元素。需要注意的是：此时 `used` 只对同一个 for 循环即同一个父节点下的遍历负责，因此 `used` 无需进行回溯，在往下层递归时使用新的 `used` （**不能排序原集合**）。
- 关于集合元素是否需要排序：在求和问题中，排序后剪枝是常见套路；在集合元素存在重复的情况下，为去重需要排序；在子集问题中：求存在重复元素的集合的递增子序列，由于是子序列，故不能对原集合进行排序（排序完的集合都是自增子序列了）。
- 切割问题：明确切割点通过横向遍历时的 `startIndex` 和 `i` 确定，且是两者间的闭区间。因此 `i` 是从 `startIndex` 开始的，且能够遍历到集合中的最后一个元素；开始递归的 `startIndex` 为集合的第一个元素，即 `startIndex = 0`；往下一层递归时，下一层的 `startIndex` 从 `i + 1` 开始。
- 子集问题：**结果中收集的是递归树中的所有节点，且需要考虑空集的问题**。而上述问题的结果均从叶节点从选取。

1. 通过递归代替需要个 k 个 for 循环的写法，穷举 k 个数的组合。为避免出现重复，通过 startIndex 记录开始位置。例如 startIndex = 1 时，其他元素可以为 2...n; 当 startIndex = 2 时，其他元素可以为 3...n。优化剪枝时，需要考虑的是在当前所记录的组合中已有多少个元素，以及剩余元素与当前组合的元素个数是否还能满足数量 k 的要求。
```C++
class Solution{
private:
    vector<int> path;
    vector<vector<int>> res;

    void backtracking(int n, int k, int startIndex){
        if(path.size() == k){
            res.emplace_back(path);
            return;
        }

        // 剪枝写法
        // for(int i = startIndex; i < n - (k - path.size()) + 1; i++)
        for(int i = startIndex; i < n; i++){
            path.push_back(i);
            backtracking(n, k, i + 1);
            path.pop_back();
        }
    }
public:
    vector<vector<int>> combine(int n, int k){
        res.clear();
        path.clear();
        backtracking(n, k, 1);
        return res;
    }
}
``` 
2. 提供的数组中的元素允许重复选取，且满足元素值是大于等于 1 的（当 `target` 为 0，如果元素值不满足上述条件，在元素允许重复选取的情况下，可能导致组合数量为无穷个的情况）。即使元素允许重复选取，但目标的还是求**组合**的数量，因此还是需要避免组合重复的情况（去重）。**对于组合问题，如果是同一个集合来求组合的话，就需要 `startIndex`**。
```C++
/* 无剪枝优化版本 */
class Solution{
private:
    vector<int> group;
    vector<vector<int>> res;

    void backtracking(const vector<int> &candidates, int target, int startIndex){
        if(target < 0) return;
        if(target == 0){
            res.emplace_back(group);
            return;

        for(int i = startIndex; i < candidates.size(); i++){
            group.push_back(candidates[i]);
            backtracking(candidates, target - candidates[i], i);
            group.pop_back();
        }
    }

public:
    vector<vector<int>> combinationSum(vector<int> &candidates, int target){
        group.clear();
        res.clear();
        backtracking();
        return res;
    }
}
```

**在求和问题中，排序后剪枝是常见的套路**。
```C++
class Solution{
private:
    vector<int> group;
    vector<vector<int>> res;

    void backtracking(const vector<int> &candidates, int target, int startIndex){
        if(target == 0){
            res.emplace_back(group);
            return;
        }

        // 进行剪枝，当 target 不满足要求时不进入下一次递归
        for(int i = startIndex; i < candidates.size() && target - candidates[i] >= 0; i++){
            group.push_back(candidates[i]);
            backtracking(candidates, target - candidates[i], i);
            group.pop_back();
        }
    }

public:
    vector<vector<int>> combinationSum(vector<int> &candidates, int target){
        group.clear();
        res.clear();
        // 先排序后进行组合
        sort(candidates.begin(), candidates.end());
        backtracking(candidates, target, 0);
        return res;
    }
}
```

3. 数组中可能包含重复元素，且每个元素在组合中只能使用一次。由于包含重复元素，因此需要考虑除上述  `startIndex` 以外的其他去重手段。另外，初始数组是无序的，为了去重需要给数组先进行排序。从而，去重的逻辑是：深层递归时不需要去重，横向遍历时需要去重，去重的方式是：当前元素与前一元素相等，且已经处理过前一元素时需要跳过当前元素。即**同一树层上使用过的需要去重，同一树枝上的都是一个组合里的元素，不用去重**。
```C++
class Solution{
private:
    vector<int> group;
    vector<int> res;

    /* 方法 1: 使用 used 数组进行标记 */
    void backtracking(const vector<int> &candidates, int target, int startIndex, vector<bool> &used){
        if(target == 0){
            res.emplace_back(group);
            return;
        }

        for(int i = startIndex; i < candidates.size() && target - candidates[i] >= 0; i++){
            if(i > 0 && candidates[i] == candidates[i - 1] && !used[i - 1]) continue;

            group.push_back(candidates[i]);
            used[i] = true;
            backtracking(candidates, target - candidates[i], i + 1, used);
            used[i] = false;
            group.pop_back();
        }

    }
    /* 方法 2：结合 startIndex 进行去重 */
    void backtracking(const vector<int> &candidates, int target, int startIndex){
        if(target == 0){
            res.emplace_back(group);
            return;
        }

        for(int i = startIndex; i < candidates.size() && target - candidates[i] >= 0; i++){
            // 去重逻辑
            if(i > startIndex && candidates[i - 1] == candidates[i]) continue;
            group.push_back(candidates[i]);
            backtracking(candidates, target - candidates[i], i + 1);
            group.pop_back();
        }
    }

public:
    vector<vector<int>> combinationSum2(vector<int> &candidates, int target){
        group.clear();
        res.clear();
        // 先排序
        sort(candidates.begin(), candidates.end());
        // 方法 1
        vector<bool> used(candidates.size(), false);
        backtracking(candidates, target, 0, used);
        // 方法 2
        backtracking(candidates, target, 0);

        return res;
    }
}
```
4. 分割会文串是*切割*问题的一种，而**切割问题也可以作为一种特殊的组合问题来处理，特殊之处在于切割不能选取非连续元素**。因此，本题同样可以采用解组合问题的方式来处理：通过递归来选择切割点，*切割点*通过 `startIndex` 来标记，每一种分割方式所得到的回文串通过 `vector<string>` 来记录，因此最终的结果形式为 `vector<vector<string>>`；递归的终止条件为 `startIndex` 超过了需要分割的对象，即 `startIndex >= s.size()`。**模拟切割线，startIndex 是上一层已经确定了的分割线，i 是这一层试图寻找的新分割线**。
```C++
class Solution{
private:
    vector<string> path;
    vector<vector<string>> res;
    // isPalindrome 的第一个索引为子串的起始位置，第二个索引为子串的结束位置
    vector<vector<bool>> isPalindrome;

    /* 通过动态规划方式事先一次性计算出 s 中的任意位置的子串是否为回文串，而动态规划也避免了重复的计算。因为回文串的条件可以总结为 s[start]=start[end] 且 s[start + 1 : end - 1] 为回文串。 */
    bool computePalindrome(const string &s){
        isPalindrome.resize(s.size(), vector<bool>(s.size(), false));
        for(int i = s.size() - 1; i >= 0; i--){
            // 需要倒序计算，保证在 i 进行时，i + 1 已经计算好了
            // 在后序使用 isPalindrome 时是以：
            // if(isPalindrome[startIndex][i]) 的形式，即以 startIndex 为起始位置，以 i 为 结束位置的字串是否为回文串。
            // todo：应该也可以顺序计算 i 的方式来设计函数
            for(int j = i; j < s.size(); j++){
                if(j == i){
                    isPalindrome[i][j] = true;
                }else if(j - i = 1){
                    isPalindrome[i][j] = s[i] == s[j];
                }else{
                    // 前一个字串是 i + 1 到 j - 1 所在区间
                    isPalindrome[i][j] = (s[i] == s[j] && isPalindrome[i + 1][j - 1]);
                }
            }
        }
    }

    /* 通过顺序计算 i 的方式来设计函数 
     * 此时 j 是子串的起始位置，i 是子串的结束位置
     */
    void computePalindrome(const string &s){
        isPalindrome.resize(s.size(), vector<bool>(s.size(), false));
        for(int i = 0; i < s.size(); i++){
            for(int j = i; j >= 0; j--){
                if(j == i){
                    isPalindrome[j][i] = true;
                }else if(i - j == 1){
                    isPalindrome[j][i] = s[i] == s[j];
                }else{
                    // 前一个字串是 j + 1 到 i - 1 所在的区间
                    isPalindrome[j][i] = (s[i] == s[j] && isPalindrome[j + 1][i - 1]);
                }
            }
        }
    }

    /* 通过双指针进行回文串的判断 */
    bool isPalindrome(const string &s, int start, int end){
        for(int i = start, j = end; i < j; i++, j--){
            if(s[i] != s[j]) return false;
        }
        return true;
    }

    void backtracking(const string &s, int startIndex){
        // 如果起始位置已经大于等于 s 的大小，说明已经找到了组分割方案了。
        if(startIndex >= s.size()){
            res.emplace_back(path);
            return;
        }

        for(int i = startIndex; i < s.size(); i++){
            // 模拟切割线，startIndex 是上一层已经确定了的分割线，i 是这一层试图寻找的新分割线
            if(isPalindrome(s, startIndex, i)){
                path.push_back(s.substr(startIndex, i - startIndex + 1));
            }else{
                // 不是回文，跳过。不再向深层递归。
                continue;
            }

            backtracking(s, i + 1);
            path.pop_back();
        }
    }

public:
    vector<vector<string>> partition(string s){
        path.clear();
        res.clear();
        backtracking(s, 0);
        return res;
    }
}
```
5. 93.复原 IP 地址与 131.分割回文串同属于“切割”问题。在做过题 131 的前提下，本题还是花了很长时间才做出来，而且做的不是很好（题解见方法 1）。主要原因是：1. 还是没有完全清除是怎么样完成切割的？切割的起始位置应该是哪里？使用 `startIndex` 表示切割点，`i` 表示切割区间的另一端，那这个区间是 `startIndex` 和 `i` 的闭区间？半开半闭区间？还是开区间？2. 在最后一个数字的判断时，如果直接对 `startIndex` 和 `s.size() - 1` 组成的区间进行判断而忽略对 `i` 的考虑时会导致结果中存在重复元素的问题；3. 如何表示处理一个满足条件的元素，是将所有的位置进行标记后再统一处理？是一边从 `s` 中取出子串后进行合并？通过 `s += ...` 的方式合并？4. 遍历结束的条件是什么，是当前的 `path` （`path` 用于记录组成结果元素的子串数组）元素数量为 4？还是进行了三次递归？

在上述代码中存在以下问题：
- 在 `checkSegment()` 函数中条件判断太多，**显得逻辑有些混乱**。而且还出现过 `num` 超出 `int` 能够表示范围的情况，因为使用 `stoi()` 函数时的输入参数由 `s` 和 `start` 及 `end` 共同决定，而 `end - start + 1` 所表示的数的位数可能很大，从而**导致运行时出错**。*然而它所需要实现的功能只是：判断子串是否是以 ‘0’ 开头的非零数字和子串所表示的数字是否大于 255*。
- 在 `backtracking()` 函数中，对最后生成一个有效 `IP` 地址的过程写的不好，充斥的不知意义的数字、对特殊情况的处理、由于不断地增加 `str` 长度可能需要多次进行内存调整等等。
- 1.同样的，`backtracking()` 的后序代码主要完成递归任务，充斥着条件判断，显得问题都没有想清楚，代码混乱。实际上，刚开始并没有想清楚应该是 `i < s.size()` 还是 ` i < s.size() - 1`，还是关于分割点的表示没有想清楚导致的；2.关于判断：当前分割的是不是最后一个数字、当前子串是否满足 `IP` 地址要求、如果当前最后一个数满足要求需要进行怎样的处理（这样是在用例不过的情况下才发现的问题，于是又添加了 `if(path.size() == 3) return`），很容易出现某些情况没有考虑到而出错，本质上还是没有想清楚问题就写解答导致的；3.还有一点，就是在解题过程中明明直到如果当前区间不满足要求，就没有后序深度递归和横向遍历的必要，但一直不确定应该怎么写。

综合上述问题和 5 中提到的内容：
- 关于分割点（切割点）：**分割点就是某一元素索引**，不要直觉地以为是索引与索引中间的什么，索引与索引（相邻）中间不存在任何东西。因此，**分割点不能是第一个元素的前面、也不能是最后一个元素的后面、前面**。**分割区间是两个索引所表示的闭区间**，因此，索引值应该以 0 开始、以集合最后一个元素的索引为结束；于是也可以推出：在不允许重复或交叉的情况下，**下一个区间的开始一定是上一个区间的结束 + 1**；**区间的表示是由 startIndex 和横向遍历时的 i 所决定的，由于是闭区间，允许 i = startIndex**，当区间的两个索引值相等时表示区间是有一个元素的；
- 关于对 `checkSegment()` 函数的修改已在上述中提到，实现不满足要求的判断即可；
- 如果当前子串不满足要求，直接结束本次横向遍历即可。由于处于函数的最后，结束横向遍历可以时可以直接 `return` 也可以 `break`;
- 为避免在 `for` 循环中出现过多的判断，可以将最后一个 `IP` 数字的判断放在结果处理中，同时还可以避免由于 `i` 在 `startIndex` 和最后一个元素间横向遍历，但最后一个元素一直取 `startIndex` 至最后的子串导致的重复问题。
- 关于 `IP` 字符串的问题：可以向上面一样到最后一个一个累加，但是费时间费空间；可以直接在给定的字符串 `s` 上插入和删除元素来实现递归和回溯，但是同样存在不断调正 `s` 的长度的问题；~~由于 `s` 的长度是已知的，需要添加的 `.` 也是已知的（3 个），可以创建一个 `string` 对象 `str`，并 `str.resize(len + 3)`，同时在递归时保存需要插入 `.` 的位置（保存前一个区间的结束索引即可，`path` 中保存该索引），在最后的处理时通过 `str.replace()` 将 `str` 中的内容用 `s.substr()` 和 `.` 替换掉就能得到 `IP` 字符串。但是这样类似于第一种方式，通过 `s.substr()` 会申请多个临时变量出来。~~

```C++
                    //或者： s.insert(i + 1, ".");
                    backtracking(s, i + 2, count + 1);
                    // 由于添加了 "."，下一层的递归开始位置为 i + 2
                    // startIndex 可能会超过 s 的最后一个元素，需要在 checkSegment 中添加对这一情况的判断
                    s.erase(s.begin() + i + 1);
                    // 回溯
                }else{
                    break;      // 结束本层的横向遍历
                }
            }
        }
    }

public:
    vector<string> restoreIPAddress(string s){
        res.clear();
        if(s.size() < 4 || s.size() >= 13) return res;
        backtracking(s, 0, 0);
        return res;
    }
}
```
6. 子集问题也可以看作一种组合问题，不过与前面组合问题不同的是：**子集问题需要将递归树中每个节点都放入结果中**，而之前涉及的组合问题、切割问题都只需要将递归树中的叶节点放入结果中。另外，**在子集问题中需要考虑空集项**。在子集问题II中，由于原集合中存在重复元素，因此需要在数层去重，去重方法同上述组合问题中所介绍，题解略。
```C++
class Solution{
private:
    vector<int> path;
    vector<vector<int>> res;

    void backtracking(const vector<int> &nums, int startIndex){
        // 子集问题，不同点是需要将树中每个节点都放入集合中，而不是只放入叶节点
        // 由于包含空集，因此不需要对 path 是否为空进行判断，path 为空时只会加入集合中一次
        res.emplace_back(path);
        if(startIndex >= nums.size()){
            return;
        }

        // 也需要避免重复，因此 i 也是从 startIndex 开始
        for(int i = startIndex; i < nums.size(); i++){
            path.push_back(nums[i]);
            backtracking(nums, i + 1);
            path.pop_back();
        }
    }

public:
    vector<vector<int>> subsets(vector<int> &nums){
        res.clear();
        path.clear();
        backtracking();
        return res;
    }
}
```
7. 关于递增子序列问题需要关注的点：1. 由于是求原集合的子序列，所以不能对原集合进行排序；2. 原集合中存在重复元素，需要考虑数层去重的问题；3. **数层去重中使用哈希表还是数组来进行标记的效率问题**：使用哈希表可以节省内存的使用，但由于需要频繁地进行 `insert` 操作，需要进行哈希映射（把 `key` 通过 `hash function` 映射为唯一的哈希值）相对费时间；使用数组也可以达到哈希表的功能，且无需进行哈希映射，所以时间消耗更小，但需要申请更多的空间，相当于是以空间换时间了。综上，当使用数组方便表示连续的元素使用情况（宗旨是使用数组空间浪费较小）可以使用数组来表示哈希表；反之，使用其他的哈希表数据结构。
```C++
class Solution{
private:
    vector<int> path;
    vector<int> res;

    void backtracking(const vector<int> &nums, int startIndex){
        if(path.size() > 1) res.emplace_back(path);

        // 使用 set 来标记使用过的元素
        unordered_set<int> used;
        for(int i = startIndex; i < nums.size(); i++){
            // 保证 path 中是递增元素
            // if(path.size() > 0 && path[path.size() - 1] > nums[i]) continue;
            if(!path.empty() && path.back() > nums[i]) continue;
            if(used.find(nums[i]) != used.end()) continue;
            
            used.insert(nums[i]);
            path.push_back(nums[i]);
            backtracking(nums, i + 1);
            // used 无需进行回溯，每一层使用新的 used
            path.pop_back();
        }
    }

    void backtracking(const vector<int> &nums, int startIndex){
        if(path.size() > 1) res.emplace_back(path);

        // 由于题中给出条件：集合中元素取值范围为 -100 <= nums[i] <= 100。因此可以使用数组来充当哈希表
        int used[201] = {0};
        for(int i = startIndex; i < nums.size(); i++){
            if(!path.empty() && path.back() > nums[i]) continue;
            if(used[nums[i] + 100]) continue;

            used[nums[i] + 100] = 1;
            path.push_back(nums[i]);
            backtracking(nums, i + 1);
            path.pop_back();
        }
    }

public:
    vector<vector<int>> findSubsequences(vector<int> &nums){
        path.clear();
        res.clear();
        backtracking(nums, 0);
        return res;
    }
}
```
8. 在排列问题中，例如对如数组 `[1,2]`，它的全排列为 `[1,2] 和 [2, 1]`，即可以先选取后面的元素再选取前面的元素。因此，在 for 循环的横向遍历中不再需要 `startIndex` 来规定遍历的起始位置，也没有了引入 `startIndex` 之后带来的去重作用。
   同时，在排列问题中还需要考虑的是在一个深度递归的过程中哪些元素被使用（在该深度递归中不允许再使用相同的元素），即在一个排列结果中同一个元素不能重复出现，这需要在深度递归中进行处理。
   在*全排列II* 问题中，也需要考虑“树层去重”的问题，**不同的是之前在“组合问题”中所使用的 `i > startIndex && nums[i] == nums[i - 1]->continue` 在排列问题中不能再使用**。原因是对于组合问题，回溯得到的结果是在横向遍历和深度递归中从集合中**顺序**取得的，同时上述判断保证了在同一个深度递归中 `startIndex` 处的元素是允许被选取的（`startIndex`是上层的 `i` + 1）。而对于排列问题，它的结果是从集合中**无序**地选取的（可以先选取前面再选取后面，也可以先选取后面再选取前面），因此 **`startIndex` 对于排列问题就是无意义的，所以如果将每次横向遍历的固定起始点 0 作为 `startIdex` 也是不可取的**。
```C++
/* 全排列，无重复元素 */
class Solution{
private:
    vector<int> path;
    vector<vector<int>> res;

    void backtracking(const vector<int> &nums, vector<bool> &used){
        if(path.size() == nums.size()) res.emplace_back(path);

        // 不需要 startIndex，遍历起始点每次都从 0 开始
        for(int i = 0; i < nums.size(); i++){
            // 已使用过的元素在同一个“树枝”中不能再次被使用
            if(used[i]) continue;
            path.push_back(nums[i]);
            used[i] = true;
            backtracking(nums, used);
            used[i] = false;
            path.pop_back();
        }
    }

public:
    vector<vector<int>> permute(vector<int> &nums){
        res.clear();
        path.clear();
        vector<bool> used(nums.size(), false);
        backtracking(nums, used);
        return res;
    }
}
```
```C++
/* 全排列，有重复元素 */
class Solution{
private:
    vector<int> path;
    vector<vector<int>> res;

    void backtracking(const vector<int> &nums, vector<bool> used){
        if(path.size() == nums.size()) res.emplace_back(path);

        for(int i = 0; i < nums.size(); i++){
            // 树层去重。不能够使用 if(i > 0 && nums[i] == nums[i - 1]) continue;
            // 是判断 used[i - 1]，而不是 used[i]
            if(i > 0 && nums[i] == nums[i - 1] && !used[i - 1]) continue;
            // 同时还要判断此时元素是否在“树枝”中被使用过
            if(used[i]) continue;

            path.push_back(nums[i]);
            used[i] = true;
            backtracking(nums, used);
            used[i] = false;
            path.pop_back();
        }
    }

public:
    vector<vector<int>> permute(vector<int> &nums){
        res.clear();
        path.clear();
        vector<bool> used(nums.size(), false);
        // 为实现后序去重，需要将 nums 排序
        sort(nums.begin(), nums.end());
        backtracking(nums, used);
        return res;
    }
}
```

9. 题目的要求是在一个 `n x n` 的棋盘上，同行、同列、同斜线上不能放置皇后棋子，求将 `n` 个皇后放在棋盘上有多少中放法。可以采用递归回溯的方法，按行进行递归并按列进行横向遍历，单层横向遍历的逻辑是某些特定位置不能放皇后，这些特定逻辑是按照上述规则来定的。当递归层数到达 `n` 层，即最后一行时，完成递归，由于测试棋盘上放置皇后的情况即为一个符合条件的结果，因此直接将棋盘放入最后结果集合中即可，避免多出一个变量来保存一个临时结果。
```C++
class Sulotion{
private:
    vector<vector<string>> res;

    /* 判断当前位置能够放入皇后棋子 
     * 由于按照行数由小到大遍历，因此只需判断比当前行数小的* 位置是否满足条件来让当前位置放入皇后
     */
    bool isValid(int row, int col, int n, vector<string> &chessboard){
        // 同列
        for(int i = 0; i <= row; i++){
            if(chessboard[i][col] == 'Q') return false;
        }
        // 同斜线-45
        for(int i = row, j = col; i >= 0 && j < n; i--, j++){
            if(chessboard[i][j] == 'Q') return false;
        }
        // 同斜线-135
        for(int i = row, j = col; i >= 0 && j >= 0; i--, j--){
            if(chessboard[i][j] == 'Q') return false;
        }
        return true;
    }

    void backtracking(int n, int row, vector<string> &chessboard){
        // row 行索引，从 0 开始。因此这里 row == n 即可
        if(row == n){
            res.emplace_back(chessboard);
            return;
        }

        for(int i = 0; i < n; i++){
            if(isValid(row, i, n, chessboard)){
                chessboard[row][i] = 'Q';
                backtracking(n, row + 1, chessboard);
                chessboard[row][i] = '.';
            }
        }
    }
public:
    vector<vector<string>> solveNQueens(int n){
        res.clear();
        vector<string> chessboard(n, string(n, '.'));
        backtracking(n, 0, chessboard);
        return res;
    }
};
```
10. 数独问题与 n 皇后问题的差别主要有：1. 在 n 皇后问题中，每一行只能放一个元素（即皇后棋子）；而在数独问题中，每一行需要在每个位置上都放有元素；2. 每个位置能够放的元素数量不一样，在 n 皇后问题中，若一个位置能够存放元素，则只能存放皇后棋子；而在数独问题中，每个位置需要考虑数字（可能是以字符表示的数字） 1~9，共 9 个元素；3. 某个位置能否放置特定元素的判断逻辑不一样：在 n 皇后问题中，需要判断在行、列和斜线上是否存在皇后棋子；而在数独问题中需要判断行、列和局部方格内是否存在同样的棋子。另外，对于 n 皇后问题中棋盘的初始状态相当于是空的，因此在判断某一位置能否放置棋子时只需要“往回看”即可；而在数独问题中，因为初始状态下在随机位置上放有数字，因此每次都要遍历整行、整列和局部。于是，在 n 皇后问题中只需要单个循环来遍历当前行（相当于以行为单位）可放皇后棋子的位置然后就可以递归、回溯。到了数独问题中，需要对每位置进行递归、回溯，所以需要给递归、回溯嵌套的循环有两层：
```C++
class Solution{
private:
    bool isValid(int row, int col, char num, vector<vector<char>> &board){
        // 判断行
        for(int i = 0; i < board[0].size(); i++){
            if(board[row][i] == num) return false;
        }
        // 判断列
        for(int i = 0; i < board.size(); i++){
            if(board[i][col] == num) return false;
        }
        // 判断局部
        // 不能只除，除完后还需要乘
        int topLeftRow = (row / 3) * 3;
        int topLeftCol = (col / 3) * 3;
        for(int i = topLeftRow; i < topLeftRow + 3; i++){
            for(int j = topLeftCol; j < topLeftCol + 3; j++){
                if(board[i][j] == num) return false;
            }
        }

        return true;
    }

    // 由于只需要找到一个解即返回，所以带来返回值
    bool backtracking(vector<vector<char>> &board){
        for(int row = 0; row < board.size(); row++){
            for(int col = 0; col < board[0].size(); col++){
                if(board[row][col] != '.') continue;
                for(char k = '1'; k <= '9'; k++){
                    if(isValid(row, col, k, board)){
                        board[row][col] = k;
                        if(backtracking(board)) return true;
                        board[row][col] = '.';
                    }
                }
                return false;
            }
        }
        // 遍历完还没有返回说明已完成了数独。直接返回 true
        return true;
    }

public:
    void solveSudoku(vector<vector<char>> &board){
        backtracking(board);
    }
};
```
