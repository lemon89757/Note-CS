# STL(Standard Template Library)

>[C语言中文网](https://c.biancheng.net/stl/)

`C++` 标准模板库的核心包括以下重要组件：
* 容器(Containers)
各种数据结构，包括向量（vector）、链表（list）、队列（queue）、栈（stack）、集合（set）、映射（map）等。

* 算法(Algorithms)
用于对容器中的元素进行各种操作，包括排序、搜索、复制、移动、变换等。这些算法在使用时**不需要关心容器的具体类型**，只需要指定要操作的范围即可。

* 迭代器(Iterators)
**用于遍历容器中的元素**，允许以统一的方式访问容器中的元素，而**不用关心容器的内部实现细节**。包括：随机访问迭代器、双向迭代器、前向迭代器和输入输出迭代器等。

* 函数对象(Function Objects)
也称**仿函数**，函数对象是**可以像函数一样调用的对象**，可以用于算法中的各种操作。包括：一元函数对象、二元函数对象、谓词等。

* 适配器(Adapters)
**用于将一种容器或迭代器适配成另一种容器或迭代器**，以满足特定的需求。包括：栈适配器（stack adapter）、队列适配器（queue adapter）和优先队列适配器（priority queue adapter）等。

* 空间配置器（内存分配器）

## 容器
用来存储数据的序列，它们提供了**不同的存储方式和访问模式**

### 序列容器
存储元素的**序列**，允许双向遍历（todo：list支持双向遍历？），特点是：
1. 线性存储
   - 元素以**线性**序列的方式存储，每个元素都有一个明确的顺序
   - 元素的存储顺序通常与插入顺序一致
2. 随机访问
   - 除了链表（std::list 和 std::forward_list）外，大多数序列容器支持随机访问，可以通过索引快速访问任意元素
3. 动态扩展
   - std::vector 和 std::deque 支持动态扩展
   - std::array 的大小是固定的，不能动态扩展
4. 插入和删除
   - std::vector 和 std::deque 在末尾进行插入和删除操作效率较高
   - std::list 和 std::forward_list（单向链表） 在任意位置进行插入和删除操作效率较高

* `std::vector`
1. 动态数组，支持快速随机访问
2. 与 C++ 数组比较
   1. 定义一个数组，需要事先确定好数组的长度 $n$，**$n$ 必须为常量**
   ```C++
   int a[n];   // n 必须为常量
   ```
   如果在实际应用中无法确定数组长度，则一般会将数组长度设为最大的可能值，但这很有可能*导致存储空间的浪费*。
   2. 在**堆空间**中动态申请内存，此时**长度可以是变量**
   ```C++
   int *p = new int[n];
   ```
   在这种方式下，数组长度固定，当出现空间不足时需要手动加大存储空间
   ```C++
   int *temp = new int[m];
   memcpy(temp, p, sizeof(int)*n); // 将原内存空间的数据全部赋值到新申请的内存空间中
   delete [] p;
   p = temp;
   ```
   3. 采用 `vector` 时大多数细节将不需要程序员关心
   ```C++
   vector<int> a;
   a.push_back(1);
   a.resize(100);    // resize 并不直接改变容量，而是通过改变 size 的大小间接地导致容量的增加
   a.clear();        // 直接删除 a 中的所有元素；a 的 size 变为 0，但 a 的 capacity 可能保持不变
   a.resize(20, -1); // 重新调整 a 的大小，并存储 20 个 -1 元素
   ```


* `std::deque`
1. 双端队列，支持快速插入和删除

* `std::list`
1. 双向链表，支持快速插入和删除，但不支持随机访问

### 关联容器
存储**键值对**，每个元素都有一个键（key）和一个值（value），并且**通过键来组织元素**。（todo：set也是存储键值对？）

* `std::set`
1. 集合，不允许重复元素
2. 有序容器，根据元素的值自动排序，通常使用默认的比较函数（如 std::less）
3. 通常使用**红黑树**（一种自平衡二叉搜索树）来实现

* `std::multiset`
1. 多重集合，允许多个重复元素具有相同的键
2. 有序容器，根据元素的值自动排序，通常使用默认的比较函数（如 std::less）
3. 通常使用**红黑树**来实现

* `std::map`
1. 映射，每个键映射到一个值
2. 有序容器，根据键的值自动排序，通常使用默认的比较函数（如 std::less）
3. 通常使用**红黑树**来实现

* `std::multimap`
1. 多重映射，存储了键值对（pair），其中键是唯一的，但值可以重复，允许一个键映射到多个值

### 无序容器
C++11 引入；哈希表，支持快速的查找、插入和删除

* `std::unordered_set`
1. 无序集合
2. 使用**哈希表**来存储元素，元素的顺序是不确定的，取决于哈希函数和哈希表的实现，而不是元素的值

* `std::unordered_multiset`
1. 无序多重集合
2. 使用**哈希表**来存储元素，元素的顺序是不确定的，取决于哈希函数和哈希表的实现，而不是元素的值
   
* `std::unordered_map`
1. 无序映射
2. 使用**哈希表**来存储元素，键的顺序是不确定的，取决于哈希函数和哈希表的实现，而不是键的值
   
* `std::unordered_multimap`
1. 无序多重映射
2. 使用**哈希表**来存储元素，键的顺序是不确定的，取决于哈希函数和哈希表的实现，而不是键的值
