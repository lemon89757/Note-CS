# 堆
>[Hello算法](https://www.hello-algo.com/chapter_heap/)

* 是一种满足特定条件的**完全二叉树**，主要分为两种类型
    - 小顶堆：任意节点的值 <= 其子节点的值
    - 大顶堆：任意节点的值 >= 其子节点的值
* 特性
    - 最底层节点靠左填充，其他层节点都被填满
    - 根节点称为“堆顶”，将底层最右边的节点称为“堆底”
    - 对于大（小）顶堆，堆顶元素（根节点）的值是最大（小）的
* 许多编程语言提供的是**优先队列（priority queue）**，这是一种*抽象的数据结构*，定义为具有优先级排序的队列。实际上，**堆通常用于实现优先队列，大顶堆相当于元素按大到小的顺序出队的优先队列**。从使用角度来看，可以将“优先队列”和“堆”看作等价的数据结构。

## 常用操作
| 方法名   | 描述   | 时间复杂度   |
|:--------:|:--------:|:--------:|
| `push()` | 元素入堆 | `O(logn)` |
| `pop()` | 堆顶元素出堆 | `O(logn)` |
| `peek()` | 访问堆顶元素 | `O(1)` |
| `size()` | 获取堆的元素数量 | `O(1)` |
| `isEmpty()` | 判断堆是否为空 | `O(1)` |

* 可以通过设置一个 `flag` 或 `Comparator` 实现“小顶堆”和“大顶堆”之间的转换。
```C++
/* 初始化 */
priority_queue<int, vector<int>, greater<int>> minHeap;     // 大于 创建 小顶堆
```

## 堆的实现
### 堆的存储与表示
  - 堆是一种完全二叉树，而完全二叉树非常适合用数组来存储，因此**使用数组来存储堆**。
  - 节点指针通过索引（数组索引）映射公式来实现：给定索引 $i$，其左子节点的索引为 $2i + 1$，右子节点的索引为 $2i + 2$，父节点的索引为 $(i - 1) / 2$，*当索引越界时，表示空节点或节点不存在*。

### 访问堆顶元素
  - 堆顶元素即为列表的首个元素

### 元素入堆
  - 给定元素 `val`，首先将其添加到*堆底*。添加之后，考虑到堆的成立条件可能已被破坏，因此**需要修复从插入节点到根节点的路径上的各个节点**，这个操作被称为*堆化（heapify）*
  - 考虑从入堆节点开始，**从底至顶执行堆化**。根据堆的特性，比较插入节点与其父节点的值，判断是否满足特性要求（大顶堆要求父节点大于等于左右子节点，小顶堆同理），不满足则将它们交换。然后继续执行此操作，从底至顶修复堆中的各个节点，**直至越过根节点或遇到无须交换的节点时结束**。
  - 设节点总数为 $n$，则树的高度为 $O(logn)$。因此，堆化操作的循环轮数最多为 $O(logn)$，**元素入堆操作的时间复杂度为 $O(logn)$**。

### 堆顶元素出堆
  - 如果直接从列表中删除首元素，那么二叉树所有节点的索引都会发生变化，这使得后续使用堆化进行修复变得困难。为了尽量减少元素的变动，采用如下操作步骤
    1. 交换堆顶元素与堆底元素（交换根节点和最右叶节点）
    2. 交换完成后，将堆底从列表中删除
    3. **从根节点开始，从顶至底执行堆化**，“从顶至底堆化”的操作方向与“从底至顶堆化”相反，将根节点的值与其两个子节点的值进行比较，将最大的子节点与根节点交换（大顶堆），然后循环执行此操作。
  - 与元素入堆操作相似，堆顶元素出堆操作的时间复杂度也为 $O(logn)$

```C++
int left(int i){
    return 2 * i + 1;
}

int right(int i){
    return 2 * i + 2;
}

int parent(int i){
    return (i - 1) / 2;     // 向下取整
}

int peek(){
    return maxHeap[0];
}

void push(int val){
    maxHeap.push_back(val);
    siftUp(size() - 1);
}

void siftUp(int i){
    while(true){
        int p = parent(i);
        // 当“越过根节点”或“节点无须修复”时，结束堆化
        if(p < 0 || maxHeap[i] <= maxHeap[p]) break;
        // 交换两节点
        swap(maxHeap[i], maxHeap[p]);
        // 循环向上堆化
        i = p;
    }
}

void pop(){
    // 判空处理
    if(isEmpty()){
        throw out_of_range("堆为空");
    }
    // 交换根节点与最右叶节点
    swap(maxHeap[0], maxHeap[size() - 1]);
    // 删除节点
    maxHeap.pop_back();
    // 从顶至底堆化
    siftDown(0);
}

void siftDown(int i){
    while(true){
        int l = left(i), r = right(i), ma = i;
        if(l < size() && maxHeap[l] > maxHeap[ma]) ma = l;
        if(r < size() && maxHeap[r] > maxHeap[ma]) ma = r;
        if(ma == i) break;
        swap(maxHeap[i], maxHeap[ma]);
        i = ma;
    }
}
```

## 建堆操作
在某些情况下，希望**使用一个列表的所有元素来构建一个堆，这个过程被称为“建堆操作”**。

### 借助入堆操作实现
- 首先创建一个空堆，然后遍历列表，依次对每个元素执行“入堆操作”，即先将元素添加至堆的尾部，再对该元素执行“从底至顶”堆化。
- 每当一个元素入堆，堆的长度就加一。由于节点是*从顶到底依次被添加进二叉树*的，因此**堆是“自上而下”构建的**。
- 记元素数量为 $n$，每个元素的入堆操作使用 $O(logn)$时间，因此**该建堆方法的时间复杂度为 $O(nlogn)$**。

### 通过遍历堆化实现
**是一种更高效的方法**，步骤为：
  1. 将列表所有元素原封不动地添加到堆中，此时堆的性质尚未得到满足
  2. **倒序遍历堆（层序遍历的倒序），依次对每个非叶节点执行“从顶至底堆化”**。
* **每当堆化一个节点后，以该节点为根节点的子树就形成一个合法的子堆**。由于是倒序遍历，因此堆是“**自下而上**”构建的。
* 之所以选择倒序遍历，是因为这样能够**保证当前节点之下的子树已经是合法的子堆**，这样堆化当前节点才是有效的。
* 由于叶节点没有子节点，因此它们天然是合法的子堆，无须堆化。最后一个非叶节点是最后一个节点的父节点，因此从它们开始倒序遍历并执行堆化。
```C++
/* 构造方法，根据输入列表建堆 */
MaxHeap(vector<int> nums){
    maxHeap = nums;
    for(int i = parent(size() - 1; i >= 0; i--)){
        siftDown(i);
    }
}
```

### 复杂度分析
1. （通过遍历堆化实现的复杂度分析）**未考虑到二叉树底层节点数量远多于顶层节点的性质**，因此下列估算并不准确：
   - 假设*完全二叉树的节点数量为 $n$，则叶节点数量为 $(n + 1) / 2$*，其中 `/` 为向下取整。因此需要堆化的节点数量为 $(n - 1) / 2$
   - 从顶至底堆化过程中，每个节点最多堆化到叶节点，因此最大迭代次数为二叉树的高度 $logn$
   - 将两者相乘，可得到整个建堆过程的时间复杂度为 `O(nlogn)`
2. （通过遍历堆化实现的复杂度分析）更为准确的计算
   - 节点“从顶至底堆化”的最大迭代次数等于该节点到叶节点的距离，正是“节点高度”
   - 通过计算“节点数量 * 节点高度”求和可以计算出需要堆化的节点的迭代次数总和为 $2^{h + 1} - h - 2$，其中 $h$ 为完美二叉树的高度 
   - 因此，**时间复杂度为 $O(2^{h}) = O(n)$**。（高度为 $h$ 的完美二叉树的节点数量为 $n = 2^{h + 1} - 1$）
**输入列表并建堆的时间复杂度为 $O(n)$，非常高效**。

## Top-K 问题
即给定一个长度为 $n$ 的无序数组，请返回数组中最大的 $k$ 个元素。

### 遍历选择
   - $k$ 轮遍历，分别在每轮中提取第 $1、2、...、k$ 大的元素，时间复杂度为 $O(nk)$
   - 此方法只适用于 $k << n$ 的情况。因为当 $k$ 与 $n$ 比较接近时，其时间复杂度趋向于 $O(n^2)$，非常耗时
   - 当 $k = n$ 时，可以得到完整的有序序列，此时等价于“选择排序”算法

### 排序
   - 对数组进行排序，再返回最右（左）边的 $k$ 个元素，时间复杂度为 $O(nlogn)$（应该需要根据具体排序算法决定）
   - “超额”完成任务，只需要找出最大的 $k$ 个元素即可，而不需要对其他元素进行排序

### 堆
**基于堆可以更高效地解决 `Top-k` 问题**

   - 初始化*小顶堆*
   - 先将数组的前 $k$ 个元素依次入堆
   - 从 $k + 1$ 个元素开始，若当前元素大于堆顶元素，则将堆顶元素出堆，并将当前元素入堆
   - 遍历完成后，堆中保存的就是最大的 $k$ 个元素
```C++
priority_queue<int, vector<int>, greater<int>> topKHeap(vector<int> &nums, int k){
    // 初始化小顶堆
    priority_queue<int, vector<int>, greater<int>> heap;
    // 将数组的前 k 个元素入堆
    for(int i = 0; i < k; i++){
        heap.push(nums[i]);
    }
    // 从第 k + 1 个元素开始，保持堆的长度为 k
    for(int i = k; i < nums.size(); i++){
        if(nums[i] > heap.top()){
            heap.pop();
            heap.push(nums[i]);
        }
    }
    return heap;
}
```
   - 总共执行了 $n$ 轮入堆和出堆，堆的最大长度为 $k$，因此时间复杂度为 $O(nlogk)$。
   - **该方法效率很高，当 $k$ 较小时，时间复杂度趋向 $O(n)$；当 $k$ 较小时，时间复杂度不会超过 $O(nlogn)$**
   - *该方法同时使用于动态数据流的场景。在不断加入数据时，可以持续维护堆内的元素，从而实现最大 $k$ 个元素的动态更新*。

## 相关问题
* 215.数组中的第 K 个最大元素

1. 对于该问题的思路：首先（方法 1），可以通过**优先级队列**（小顶堆，`priority_queue<int, vector<int>, greater<int>>`）快速找到数组中的第 K 个最大元素。但是考虑到：该题更多的是需要考察对堆操作的熟悉程度，因此不能直接使用 C++ 提供的上述数据结构，**需要自己完成建堆等操作**（建堆操作时间复杂度为 `O(n)`，而出堆操作的时间复杂度是 `O(klogn)`。通过建立大顶堆，然后删除 `K - 1` 个堆顶元素，即可得到第 K 个最大值）。另外（方法 2），可以通过**快速排序**的方式来实现对数组中第 K 个最大元素的寻找，快速排序的时间复杂度为 `O(nlogn)`。但是现在只关心第 K 个最大元素，而无需将数组完全排序，[时间复杂度的期望为 `O(n)`](https://leetcode.cn/problems/kth-largest-element-in-an-array/solutions/307351/shu-zu-zhong-de-di-kge-zui-da-yuan-su-by-leetcod-2/?envType=study-plan-v2&envId=top-100-liked)。

```C++
/* 方法 1：基于堆 */
class Solution{
private:
    /* 建堆相关操 
     * 1. 首先，堆是一颗完全二叉树，非常适合通过数组来保存；
     * 2. i 位置的父节点、左右子节点的计算方式
     * 3. 入堆和出堆操作以及由入堆和出堆导致的调整操作
     * 4. 建堆操作，优先使用从底至顶的堆化操作（是指先让底部的子树先构成合法的子堆，然后逐层递进上去，每层递进的过程中需要从上至下进行调整），效率高
     */
    
    /* i 位置的左子节点 */
    int left(int i ){
        return 2 * i + 1;
    }

    /* i 位置的右子节点 */
    int right(int i){
        return 2 * i + 2;
    }

    /* i 位置的父节点 */
    int parent(int i){
        return (i - 1) / 2;
        // 也可以是 return i / 2 - 1;
    }

    /* 从 i 位置以从下至上的方式进行堆化操作，可以用于元素入栈后的调整 */
    void siftUp(int i){
        // 基本思想是：求 i 位置的父节点，大顶堆时，求当前节点与父节点的最大值并使父节点为最大值
        // 如果父节点已是最大值，则说明已完成调整；如果父节点超出数组的表示范围说明也完成调整
        while(true){
            int p = parent(i);
            if(p < 0 || maxHeap[p] >= maxHeap[i]) break;
            swap(maxHeap[p], maxHeap[i]);
            i = p;
        }
    }

    /* 从 i 位置以从上至下的方式进行堆化操作，可以用于建堆和出栈时的调整 */
    void siftDown(int i){
        while(true){
            // 基本思想是：求 i 位置的左右子节点，大顶堆时，使 i 位置为三个节点中的最大值
            // 如果当前位置已为最大值，则说明已完成调整
            int l = left(i), r = right(i), ma = i;    // 通过 ma 记录最大值的位置 
            // 需要对 l 和 r 是否在数组表示范围内进行判断
            if(l < maxHeap.size() && maxHeap[l] > maxHeap[ma]) ma = l;
            if(r < maxHeap.size() && maxHeap[r] > maxHeap[ma]) ma = r;
            if(i == ma) break;
            swap(maxHeap[i], maxHeap[ma]);
            i = ma;
        }
    }

    int top(){
        return maxHeap[0];
    }

    /* 元素的出堆操作，出堆是将堆顶元素弹出 */
    void pop(){
        // 防止栈为空
        if(maxHeap.empty()) return;
        // 基本思想是：交换堆顶和堆顶元素，将堆底元素弹出，然后从顶至底进行堆化操作
        swap(maxHeap[0], maxHeap[maxHeap.size() - 1]);
        maxHeap.pop_back();
        siftDown(0);
    }

    /* 将元素 val 入栈*/
    void push(int val){
        // 基本思想是：将 i 加入到数组的最后，然后从底至顶进行堆化操作
        maxHeap.push_back(val);
        siftUp(maxHeap.size() - 1);
    }

    /* 建堆操作 */
    void buildMaxHeap(vector<int> &nums){
        maxHeap = nums;
        // 基本思想是：在完全二叉树（堆）中，叶节点自身便能够构成合法子堆
        // 因此从叶节点的上一层开始从底至上顶进行堆化操作
        
        // int p;
        // for(int i = maxHeap.size() - 1; i >= 0; i--){
        //     p = parent(i);
        //     siftDown(p);
        // }
        // 上述代码的问题点是，两个叶节点共有父节点时重复操作
        // 因此可以直接从最后一个叶节点的父节点开始遍历，不对叶节点进行遍历
        for(int i = parent(maxHeap.size() - 1); i >= 0; i--){
            siftDown(i);
        }
    }


private:
    vector<int> maxHeap;    // 大顶堆

public:
    int findKthLargest(vector<int> &nums, int k){
        // 建立大顶堆
        buildMaxHeap(nums);
        while(--k){
            pop();
        }
        return top();
    }
};

/* 基于堆的简便写法 */
class Solution{
// 题中只需建堆操作、出栈操作
private:
    int left(int i){
        return 2 * i + 1;
    }

    int right(int i){
        return 2 * i + 2;
    }

    int parent(int i){
        return (i - 1) / 2;
    }

    /* 出栈和建堆操作时需要从顶至顶的堆化操作 */
    void siftDown(vector<int> &maxHeap, int i){
        while(true){
            int l = left(i), r = right(i), ma = i;
            if(l < maxHeap.size() && maxHeap[l] > maxHeap[ma]) ma = l;
            if(r < maxHeap.size() && maxHeap[r] > maxHeap[ma]) ma = r;
            if(ma == i) break;
            swap(maxHeap[i], maxHeap[ma]);
            i = ma;
        }
    }

    void pop(vector<int> &maxHeap){
        if(maxHeap.empty()) return;
        swap(maxHeap[0], maxHeap[maxHeap.size() - 1]);
        maxHeap.pop_back();
        siftDown(maxHeap, 0);
    }

    void buildMaxHeap(vector<int> &nums){
        for(int i = parent(nums.size() - 1); i >= 0; i--){
            siftDown(nums, i);
        }
    }
public:
    int findKthLargest(vector<int> &nums, int k){
        buildMaxHeap(nums);
        while(--k){
            pop(nums);
        }
        return nums.front();
    }
};

/* 方法 2：基于快速排序 */
class Solution{
private:
    int quickSelect(vector<int> &nums, int start, int end, int k){
        // 目标区间已完成排序，直接返回目标值即可。
        if(end == start) return nums[k];

        // 快排部分
        // 选择左边端点为基准点
        int partition = nums[start], i = start - 1, j = end + 1;
        while(i < j){
            do i++; while(nums[i] < partition);
            do j--; while(nums[j] > partition);
            if(i < j) swap(nums[i], nums[j]);
        }
        // 通过上述排序，只能保证 j 位置的右边都是比 nums[j] 大的值
        // 不能保证 j 位置的左边满足都比 nums[j] 小
        // 或者反过来，在 i 位置左边的均比 nums[i] 要小，但不对 i 位置右边保证
        // eg: nums = [7, 6, 5, 4, 3, 2, 1]

        // 区间选择为 [j + 1, end] 和 [start, j]
        if(k <= j) return quickSelect(nums, start, j, k);     // 目标位置在区间 [start, j] 内，需要对此区间进行排序
        else return quickSelect(nums, j + 1, end, k);         // 目标位置在区间 [j + 1, end] 内
    }

public:
    int findKthLargest(vector<int> &nums, int k){
        // 需要注意，quickSelect 的第三个参数是排序后的目标位置
        // 而给定的是第 k 个最大元素，在从小到大排序的数组中相当于是 n - K 位置
        return quickSelect(nums, 0, nums.size() - 1, nums.size() - k);
    }
};

class Solution{

        if(end == start) return nums[k];

        // 快排部分
        // 选择左边端点为基准点
        int partition = nums[end], i = start - 1, j = end + 1;
        while(i < j){
            do i++; while(nums[i] < partition);
            do j--; while(nums[j] > partition);
            if(i < j) swap(nums[i], nums[j]);
        }
        // 通过上述排序，只能保证 j 位置的右边都是比 nums[j] 大的值
        // 不能保证 j 位置的左边满足都比 nums[j] 小
        // 或者反过来，在 i 位置左边的均比 nums[i] 要小，但不对 i 位置右边保证
        // eg: nums = [7, 6, 5, 4, 3, 2, 1]

        // 区间选择为 [i, end] 和 [start, i - 1]
        if(k < i) return quickSelect(nums, start, i - 1, k);     // 目标位置在区间 [start, i - 1] 内，需要对此区间进行排序
        else return quickSelect(nums, i, end, k);         // 目标位置在区间 [i, end] 内
    }

public:
    int findKthLargest(vector<int> &nums, int k){
        // 需要注意，quickSelect 的第三个参数是排序后的目标位置
        // 而给定的是第 k 个最大元素，在从小到大排序的数组中相当于是 n - K 位置
        return quickSelect(nums, 0, nums.size() - 1, nums.size() - k);
    }
};
```
