# 哈希表

> [hello算法](https://www.hello-algo.com/chapter_hashing/)

哈希表(`Hash Table`)，又称**散列表**，通过建立 `key`与 `value`之间的映射，实现高效的元素查询。哈希表增删改查的时间复杂度为 `O(1)`。

## 应用

1. 用来快速判断一个元素是否出现在集合中。

## 实现

### 数组实现

1. 数组中每个空位称为**桶** `bucket`，每个桶可以存储一个键值对。
2. 查询操作就是找到 `key`对应的桶，并在桶中获取 `value`，基于 `key`通过**哈希函数**定位对应的桶。

3.`哈希函数`的作用是**将一个较大的输入空间映射到一个较小的输出空间**。在哈希表中，输入控件-`key`，输出控件-`bucket`（数组索引）。于是，可以通过哈希函数得到该 `key`对应的键值对在数组中的存储位置。

4. 流程大致是：

   a. 通过某种哈希算法 `hash()`计算 `key`对应的哈希值；

   b. 将哈希值对桶数量（数组长度）`capacity`**取模**，从而获取该 `key`对应的数组索引；

## 哈希冲突

将一个较大的输入空间映射到一个较小的输出空间，理论上一定存在**多个输入对应同一个输出**的情况。

**负载因子**：哈希表元素数量除以桶数量，**用于衡量哈希冲突的严重程度，也常作为哈希表扩容的触发条件**（JAVA 0.75 扩容：x2）。

### 措施

1.**扩容**：哈希表容量越大，多个 `key`被分配到同一个桶中的概率就越低，冲突就越少。但是扩容需要将所有键值对从旧表迁移至新表，耗时；同时，需要重新计算所有键值对的哈希值，增加了扩容的开销（**非必要不扩容**）。

2.**改良哈希表数据结构**

    2.1 开放寻址：线性探索、平方探索、多次哈希

    2.2 链式寻址

## 哈希算法
### 目标
为实现 “既快又稳” 的哈希表数据结构，哈希算法应具备如下特点：
- 确定性：相同的输入产生相同的输出；
- 效率高：哈希值的计算过程应该足够块，计算开销小；
- 均匀分布：算法应使得键值对均匀分布在哈希表中；分布越均匀，哈希冲突的概率越低；

### 应用
- 密码存储：系统不直接存储用户密码，而是密码的哈希值；当用户输出密码时，系统计算对应的哈希值并与存储的哈希值进行比较；
- 数据完整性检查：数据发送方可以计算数据的哈希值并将其一并发送；接收方可以重新计算收到数据的哈希值，并与接收值进行比较；
- 密码学：单向性、抗碰撞性、雪崩效应

### 设计
简单的哈希算法：
1. 加法哈希：对输入的每个字符的 `ASCII` 码进行相加，将得到的总和作为哈希值；
2. 乘法哈希：利用乘法的不相关性，每轮乘以一个常数，将各个字符的 `ASCII` 码累积到哈希值中；
3. 异或哈希：将输入数据的每个元素通过异或操作累积到一个哈希值中；
4. 旋转哈希：将每个字符的 `ASCII` 码累积到一个哈希值中，每次累积前都会对哈希值进行旋转操作；
```C++
/* 加法哈希 */
int addHash(string key){
  long long hash = 0;
  const int MODULUS = 1000000007;
  for(unsigned char c : key){
    hash = (hash + (int) c) % MODULUS;
  }
  return (int)hash;
}
/* 乘法哈希 */
int mulHash(string key){
  long long hash = 0;
  const int MODULUS = 1000000007;
  for(unsigned char c : key){
    hash = (31 * hash + (int)c) % MODULUS;
  }
  return (int)hash;
}
/* 异或哈希 */
int xorHash(string key){
  int hash = 0;
  const int MODULUS = 1000000007
  for(unsigned char c : key){
    hahs ^= (int)c;
  }
  return hash & MODULUS;
}
/* 旋转哈希 */
int rotHash(string key){
  long long hash = 0;
  const int MODULUS = 1000000007;
  for(unsigned char c : key){
    hash = ((hash << 4) ^ (hash >> 28) ^ (int)c) % MODULUS;
  }
  return (int)hash;
}
```
在上述代码中，都对大质数 100000007 取模：**使用大质数作为模数，可以最大化地保证哈希值均匀分布**。因为质数不与其他数字存在公约数，可以减少因取模操作而产生的周期性模式，从而减少哈希冲突。 

### 常见哈希算法
- `MD5`
- `SHA-1`
- `SHA-2`
- `SHA-3`

- 补充：
  - `unordered_map<key, value>` 除了比较 `key` 计算得到的哈希值外，还会比较 `key` 本身是否相同。只有当两者都相同时才会将两个值放入同一个 `bucket` 中。**即使两个键的哈希值相同，它们也不一定相等。键的比较操作可以解决哈希冲突，确保只有真正相等的键才会被视为相同**。例如：
  ```C++
  // 情况一
  unordered_map<size_t, vector<string>> count;
  // 情况二
  unordered_map<array<int, 26>, vector<string>, decltype(getHashValue)> mp(0, getHashValue);

  // 通过以下方式计算哈希值
  size_t getHashValue(array<int, 26> &arr){
    return accumulate(arr.begin(), arr.end(), 0u, [&](size_t acc, int num){
      return (acc << 1) ^ hash<int>{}(num);
    });
  }
  ```
  在上述代码中，情况一和情况二都通过 `getHashValue()` 函数直接或间接地计算出哈希值。对于字符串 `"ac"` 和 `"bbdd"`，通过上述函数得到同样的哈希值。在情况一中，两个字符串它们被放入同一个 `vector` 中。**因为哈希值即键本本身，因此 `"ac"` 和 `bbdd` 被放入相同的 `vector` 中**；对于情况二，它们被放入不同的 `vector` 中。因为此时即使 `"ac"` 和 `"bbdd"` 的哈希值相等，还会继续比较键值是否相等，**然而当 `array<int, 26>` 作为键值时，显然它们两者是不相等的**。

## 哈希表的应用及相关比较

### 数组、链表、哈希表的比较

| 数组 | 链表 | 哈希表 |

| ---- | -------- | -------- |

| 查找元素 | O(n) | O(n) | O(1) |

| 添加 | O(1) | O(1) | O(1) |

| 删除 | O(n) | O(n) | O(1) |

### `C++`中 `set`和 `map`的底层实现及优劣

常见的三种哈希结构

> [代码随想录](https://www.programmercarl.com/%E5%93%88%E5%B8%8C%E8%A1%A8%E7%90%86%E8%AE%BA%E5%9F%BA%E7%A1%80.html#%E5%93%88%E5%B8%8C%E5%87%BD%E6%95%B0)：

* 数组
* set
* map

相当于上述三种结构可以基于 `hash`表实现。数组通过索引访问也可视为一种哈希映射。

**比较**：

- 数组与 `set`：

  a. `set`占用空间比数组大：因为 `set`需要存储额外的信息来维护其集合的特性，如元素的唯一性等，而数组只是简单地按顺序存储元素

  b. `set`的操作速度通常比数组慢，这是因为 `set`在将数值映射到 `key`上时需要进行 `hash`计算，这个过程会消耗一定的时间，而数组则可以直接通过索引访问元素，操作相对更直接、更快速。两者的性能差异会随着数据量的增加而逐渐体现出来。

1. 集合 `set`

| 集合 | 底层实现 | 是否有序 | 数值是否可重复 | 能否更改数值 | 查询效率 | 增删效率 |

| ---- | -------- | -------- | -------------- | -------------- | -------- | -------- |

| std::set | 红黑树 | 有序 | 否 | 否 | O(log n) | O(log n) |

| std::multiset | 红黑树 | 有序 | 是 | 否 | O(log n) | O(log n) |

| std::unordered_set | 哈希表 | 无序 | 否 | 否 | O(1) | O(1) |

**红黑树**是一种平衡二叉搜索树，所以 `key`值是有序的，但 `key`不可以修改，修改 `key`值会导致整棵树的错乱，所以只能删除和增加。

2. 映射 `map`

| 映射 | 底层实现 | 是否有序 | 数值是否可重复 | 能否更改数值 | 查询效率 | 增删效率 |

| ---- | -------- | -------- | -------------- | -------------- | -------- | -------- |

| std::map | 红黑树 | key有序 | key不可重复 | key不可修改 | O(log n) | O(log n) |

| std::multimap | 红黑树 | key有序 | key可重复 | key不可修改 | O(log n) | O(log n) |

| std::unordered_map | 哈希表 | key无序 | key不可重复 | key不可修改 | O(1) | O(1) |

当需要使用集合来解决问题时，优先使用 `unordered_set`，因为它的查询和增删效率是最优的，如果需要集合是有序的，那么就用 `set`；如果要求不仅有序还要有重复数据的话，那么就用 `multiset`。

3.`unordered_set`和 `hash_set`

`C++`标准库和民间高手造的轮子，其他三种数据类型同理。

   ```C++
   // 1. 242.有效的字母异位词；
   // 2. 383.赎金信
   /* 方法 1：通过字符串作为哈希表的键 */
   class Solution{
    public:
      vector<vector<string>> groupAnagrams(vector<string> &strs){
        string cur;
        vector<vector<string>> res;
        unordered_map<string, vector<string>> mp;
        unordered_map<string, vector<string>>::iterator it;

        for(const string &str : strs){
          cur = str;
          sort(cur.begin(), cur.end());
          it = mp.find(cur);
          if(it != mp.end()){
            it->second.push_back(str);
          }else{
            mp.insert({cur, vector<string>{str}});
            // or mp.insert({cur, {str}});
            // or mp.insert(make_pair(cur, vector<string>{str}));     // std::make_pair 会自动推导模板参数的类型，因此不需要显式指定类型；
          }
        }

        for(it = mp.begin(); it != mp.end(); it++){
          res.push_back(it->second);
        }

        return res;
      }
   };
   /* 方法 2：通过自定义哈希表的哈希函数 */
   class Solution{
    public:
      vector<vector<string>> groupAnagrams(vector<string> &strs){
        // 自定义哈希表的哈希函数，定义一个函数对象
        // fn 也是一个函数对象，可以通过 fn 计算整形变量的哈希值
        // size_t 明确函数对象的返回值类型
        auto hashFunc = [fn = hash<int>{}](const array<int, 26> &arr) -> size_t {
          // 自定义累加函数
          return accumulate(arr.begin(), arr.end(), 0u, [&](size_t acc, int num){
            return (acc << 1) ^ fn(num);
          });
        };

        // 第三个模板参数填入哈希函数的类型
        unordered_map<array<int, 26>, vector<string>, decltype(hashFunc)> mp(0, hashFunc);
        array<int, 26> arr;
        for(const string str : strs){
          arr = array<int, 26>{0};
          for(const char c : str){
            arr[c - 'a']++;
          }
          mp[arr].push_back(str);
        }

        vector<vector<string>> res;
        for(auto it = mp.begin(); it != mp.end(); it++){
          res.push_back(it->second);
        }

        return res;
      } 
   };
   // 3. 49.字母异位词分组
   // 4. 438. 找到字符串中所有字母异位词 
   ```

7. 统计相似字符串*对数*。字符串仅由小写字母组成，因此一个字符串含有的字符集合（只统计字符是否在字符串中出现），**可以用一个 26 为的二进制数表示状态**。遍历字符串集合，并用哈希表统计每个字符串状态及出现的次数，可以求得最终结果。另外，需要注意的是题目要求的是相似字符串的对数，因此**当前字符串的状态可以搭配出的新对数为哈希表中该状态出现的次数**：
```C++
/* 遍历方式 1 */
class Solution{
  public:
    int similarPairs(vector<string> &words){
      int res = 0;
      unordered_map<int, int> cnt;

      for(int i = 0; i < words.size(); i++){
        int state = 0;
        for(int j = 0; j < words[i].size(); j++){
          state |= (1 << (words[i][j] - 'a'));
        }
        res += cnt[state];
        cnt[state]++;
      }
    }
}

/* 遍历方式 2 */
class Solution{
  public:
    int similarPairs(vector<string> &words){
      int res = 0;
      unordered_map<int, int> cnt;  // 哈希表，用于统计字符串对应状态出现的次数

      for(const string &word : words){
        int state = 0;
        for(const char &c : word){
          state |= (1 << (c - 'a'));
        }
        res += cnt[state];        // 新增的对数等于原来哈希表中 state 出现的次数
        cnt[state]++;
      }
      
      return res;
    }
}
```
