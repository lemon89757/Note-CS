## 动态规划问题及解题步骤
动态规划中当前状态可以由前一时刻状态推导出来。即动态规划问题一般涉及一个**状态序列，其中当前状态与之前状态相关**。解题步骤一般为：
1. 确定 `dp` 数组以及下标的含义
2. 确定递推公式
3. `dp` 数组如何初始化
4. 确定遍历顺序
5. 举例推导 `dp` 数组

`Debug` 时，最好的方式就是把 `dp` 数组打印出来，并与预期进行对比。

3. 要求是达到楼层顶部的最低花费，且从题中可知：不能只是停在最后一阶楼梯上，**需要跨过最后一阶楼梯才算达到楼层顶部**。如何表示“达到楼层顶部”是本问题比较关键的点，此时需要明确动态规划时，`dp` 数组下标的含义。如果将 `dp[i]` 解释为跨过第 `i` 阶楼梯时的最低消费，此时就会出现一个问题：跨过第 `i` 阶楼梯后的具体位置是哪里？由于题中允许一次跨 1 或 2 个台阶，因此跨过 `i` 后的具体位置无法确定，也就无法递推出后序的动态转换关系；可以换一种思路，因为到达楼顶的两种可能为：倒数第二阶跨两级台阶，从而达到楼顶；倒数第一阶跨一阶到达楼顶。此时，可以将楼顶视为在最后一级台阶后还存在的一个台阶，通过将 `dp[i]` 解释为**到达**第 `i` 级台阶的最低花费。从而，最终的 `dp` 数组长度为原数组长度加 1（最后一个元素表示为楼顶）。
```C++
class Solution{
public:
    int minCostClimbingStairs(vector<int>& cost){
        vector<int> dp(cost.size() + 1, 0);
        // 因为题中给出：允许直接从第 1 和 2 级台阶开始，因此 dp[0] 和 dp[1] 均初始化为 0
        // 动态转换公式：dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2])
        for(int i = 2; i <= cost.size(); i++){
            dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2]);
        }
        return dp.back();
    }
}
```

7. 0-1背包问题：有 n 件物品和一个最多能背重量为 w 的背包。第 i 件物品的重量是 weight[i]，得到的价值是 value[i]。**每件物品只能用一次**，求解将哪些物品装入背包里物品价值总和最大。
   * 暴力解法：单独考虑每件物品是否放入背包中，有 $2^n$ 种放法，复杂度是 `O(2^n)`。**所以暴力解法是指数级别的时间复杂度，进而才需要动态规划来进行优化**。
   * 动态规划：动态规划数组使用二维表示，即 `dp[i][j]`，表示从下标 0至i 的物品中进行选择，当背包容量为 j 时，背包能够容纳的最大价值。于是，可以有递推关系：`dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i])`，此时需要满足 `i >= weight[i]`。上述递推关系表示：当背包容量为 j，从下标 0至i 的物品中进行选择时，最大的物品价值可能是：在相同背包容量情况下，从下标 0至i - 1 中进行物品选择（即不将第 i 处的物品放入背包）；将第 i 处放入背包，背包容量变为 `i - weight[i]` 后，从下标 0至i - 1 背包能够容纳的最大价值与当前第 i 个物品的价值之和。于是，代码如下：
    ```C++
    #include <iostream>
    #include <vector>

    using namespace std;

    int main(){
        int m, n;
        cin >> m >> n;

        vector<int> cost(m);
        vector<int> value(m);
        for(int i = 0; i < m; i++){
            cin >> cost[i];
        }
        for(int i = 0; i < m; i++){
            cin >> value[i];
        }

        vector<vector<int>> dp(m, vector<int>(n + 1, 0));
        for(int i = cost[0]; i <= n; i++){
            dp[0][i] = cost[0];
        }

        // 先遍历背包还是先遍历物品都没关系
        // 因为 dp 为二维数组，不会有覆盖
        // 从左上角往右下角遍历
        for(int i = 1; i < m; i++){
            for(int j = 0; j <= n; j++){
                if(j < cost[i]) dp[i][j] = dp[i - 1][j];
                else: dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - cost[i]] + value[i]);
            }
        }

        cout << dp[m - 1][n] << endl;
        return 0;
    }
    ```
    * 动态规划一维表示。在上述内容中，可对动态规划数组进行压缩，从二维表示缩减到一维表示：`dp[j] = max(dp[j], dp[j - weight[i]] + value[i])`，其中 `dp[j]` 表示容量为 j 的背包所能容纳的最大价值。该公式是对上述内容在 `i` 层面上的缩减，相当于将 `i` 固定在物品数组的最大下标上。该递推公式意义与上述内容相似。一维表示需要注意的点：首先在遍历顺序上，**需要对背包容量从大至小进行遍历，这是因为从小到达的遍历可能会使得小消耗量的物品在背包容量较小时被放入。同时结合递推公式，当遍历到较大容量背包时还可能再次放入相同物品，这是违反了物品只能放入一次的要求**；由于需要对背包容量从大到小进行遍历，此时**只能先遍历物品，再遍历背包**。如果先遍历背包，就会导致每种背包容量都只会放入一个物品。*对于背包容量的遍历顺序，在二维动态规划数组中，由于限制了物品选择选择范围，因此当前需要考虑的只是是否需要将当前物品放入背包中；而在一维动态规划数组中，相当于取消了物品选择范围的限制，每次都是从题目中给定的物品中选择，因此（如果从小到大遍历背包）可能存在小背包放入了物品后，大背包在此基础上又放入了相同的物品*。代码如下：
    ```C++
    #include <iostream>
    #include <vector>

    using namespace std;

    int main(){
        int m, n;
        cin >> m >> n;

        vector<int> cost(m);
        vector<int> value(m);
        for(int i = 0; i < m; i++){
            cin >> cost[i];
        }
        for(int i = 0; i < m; i++){
            cin >> value[i];
        }

        vector<int> dp(n + 1, 0);
        for(int i = 0; i < m; i++){
            // j >= cost[j]，确保更新公式正确；若该不等式不成立，则不需要更新
            for(int j = n; j >= cost[i]; j--){
                dp[j] = max(dp[j], dp[j - cost[i]] + value[i]);
            }
        }

        cout << dp.back() << endl;

        return 0;
    }
    ```
