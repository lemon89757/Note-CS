## 动态规划问题及解题步骤
动态规划中当前状态可以由前一时刻状态推导出来。即动态规划问题一般涉及一个**状态序列，其中当前状态与之前状态相关**。解题步骤一般为：
1. 确定 `dp` 数组以及下标的含义
2. 确定递推公式
3. `dp` 数组如何初始化
4. 确定遍历顺序
5. 举例推导 `dp` 数组

`Debug` 时，最好的方式就是把 `dp` 数组打印出来，并与预期进行对比。

## 相关问题
### 0-1 背包问题
- 纯 0-1 背包问题：给定背包容量，求装满背包的最大价值是多少；
- 416.分割等和子集：给定背包容量，求能不能装满这个背包；
- 1049.最后一块石头的重量II：给定背包容量，尽可能状装，最多能装多少（同纯 0-1 背包）；
- 494.目标和：给定背包容量，装满背包有多少种方法；
- 474.一和零：给定背包容量，求装满背包最多有多少个物品；
### 完全背包问题
- 纯完全背包问题：在 0-1 背包基础之上，允许物品多次放入背包；当求背包的最大装入量时，在背包与物品的遍历顺序上没有要求；
- 518.零钱兑换II：装满背包容量有多少种组合方式，注意背包与物品的先后遍历顺序；
- 377.组合总数IV：装满背包容量有多少种排列方式，注意背包与物品的先后遍历顺序；
- 322.零钱兑换，279.完全平方数：求装满背包容量所需的物品最少数量，允许物品多次放入背包，背包与物品的遍历顺序不影响最终的结果；
- 139.单词拆分：允许从集合中多次选取字符串，但选取的字符串需要按照一定顺序才能平凑出目标字符串，因此是排列问题，需要注意背包与物品的先后遍历顺序；
### 多重背包问题
* 问题描述：有 N 种物品和一个容量为 V 的背包。第 i 种物品最多有 Mi 件可用，每件耗费的空间是 Ci，价值是 Wi。求解将哪些物品装入背包可使这些物品的耗费的空间总和不超过背包容量，且价值总和最大。
* 题解：将多重背包问题转换为 0-1 背包问题。将相同的物品展开为 Mi 件放入物品集合种即成为 0-1 背包问题。

### 动态规划-动态数组元素表示范围
**在该类问题中，首先需要判断当前位置判断条件的成立与结果是否依赖于前面位置**。存在依赖关系时，动态数组往往只表示特定位置的结果，而最终结果需要根据题意单独记录；不存在依赖关系时，动态数组往往表示一定范围内的结果，此时最终结果往往可以直接从动态数组最末尾元素中获取。另外，还有一点就是**还需要判断当前位置的转换关系是只能从前面一个位置得到，还是需要考虑前面的所有位置**。
* 只表示当前位置：最长递增子序列（*子序列：可不连续；子数组，子串：需要连续*）、最长连续递增序列、最长重复子数组、最大子序和；
* 表示从开始至当前位置：最长公共子序列、不相交的线、不同子序列；

3. 要求是达到楼层顶部的最低花费，且从题中可知：不能只是停在最后一阶楼梯上，**需要跨过最后一阶楼梯才算达到楼层顶部**。如何表示“达到楼层顶部”是本问题比较关键的点，此时需要明确动态规划时，`dp` 数组下标的含义。如果将 `dp[i]` 解释为跨过第 `i` 阶楼梯时的最低消费，此时就会出现一个问题：跨过第 `i` 阶楼梯后的具体位置是哪里？由于题中允许一次跨 1 或 2 个台阶，因此跨过 `i` 后的具体位置无法确定，也就无法递推出后序的动态转换关系；可以换一种思路，因为到达楼顶的两种可能为：倒数第二阶跨两级台阶，从而达到楼顶；倒数第一阶跨一阶到达楼顶。此时，可以将楼顶视为在最后一级台阶后还存在的一个台阶，通过将 `dp[i]` 解释为**到达**第 `i` 级台阶的最低花费。从而，最终的 `dp` 数组长度为原数组长度加 1（最后一个元素表示为楼顶）。
```C++
class Solution{
public:
    int minCostClimbingStairs(vector<int>& cost){
        vector<int> dp(cost.size() + 1, 0);
        // 因为题中给出：允许直接从第 1 和 2 级台阶开始，因此 dp[0] 和 dp[1] 均初始化为 0
        // 动态转换公式：dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2])
        for(int i = 2; i <= cost.size(); i++){
            dp[i] = min(dp[i - 1] + cost[i - 1], dp[i - 2] + cost[i - 2]);
        }
        return dp.back();
    }
}
```

7. 0-1背包问题：有 n 件物品和一个最多能背重量为 w 的背包。第 i 件物品的重量是 weight[i]，得到的价值是 value[i]。**每件物品只能用一次**，求解将哪些物品装入背包里物品价值总和最大。
   * 暴力解法：单独考虑每件物品是否放入背包中，有 $2^n$ 种放法，复杂度是 `O(2^n)`。**所以暴力解法是指数级别的时间复杂度，进而才需要动态规划来进行优化**。
   * 动态规划：动态规划数组使用二维表示，即 `dp[i][j]`，表示从下标 0至i 的物品中进行选择，当背包容量为 j 时，背包能够容纳的最大价值。于是，可以有递推关系：`dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - weight[i]] + value[i])`，此时需要满足 `i >= weight[i]`。上述递推关系表示：当背包容量为 j，从下标 0至i 的物品中进行选择时，最大的物品价值可能是：在相同背包容量情况下，从下标 0至i - 1 中进行物品选择（即不将第 i 处的物品放入背包）；将第 i 处放入背包，背包容量变为 `i - weight[i]` 后，从下标 0至i - 1 背包能够容纳的最大价值与当前第 i 个物品的价值之和。于是，代码如下：
    ```C++
    #include <iostream>
    #include <vector>

    using namespace std;

    int main(){
        int m, n;
        cin >> m >> n;

        vector<int> cost(m);
        vector<int> value(m);
        for(int i = 0; i < m; i++){
            cin >> cost[i];
        }
        for(int i = 0; i < m; i++){
            cin >> value[i];
        }

        vector<vector<int>> dp(m, vector<int>(n + 1, 0));
        for(int i = cost[0]; i <= n; i++){
            dp[0][i] = cost[0];
        }

        // 先遍历背包还是先遍历物品都没关系
        // 因为 dp 为二维数组，不会有覆盖
        // 从左上角往右下角遍历
        for(int i = 1; i < m; i++){
            for(int j = 0; j <= n; j++){
                if(j < cost[i]) dp[i][j] = dp[i - 1][j];
                else: dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - cost[i]] + value[i]);
            }
        }

        cout << dp[m - 1][n] << endl;
        return 0;
    }
    ```
    * 动态规划一维表示。在上述内容中，可对动态规划数组进行压缩，从二维表示缩减到一维表示：`dp[j] = max(dp[j], dp[j - weight[i]] + value[i])`，其中 `dp[j]` 表示容量为 j 的背包所能容纳的最大价值。该公式是对上述内容在 `i` 层面上的缩减，相当于将 `i` 固定在物品数组的最大下标上。该递推公式意义与上述内容相似。一维表示需要注意的点：首先在遍历顺序上，**需要对背包容量从大至小进行遍历，这是因为从小到达的遍历可能会使得小消耗量的物品在背包容量较小时被放入。同时结合递推公式，当遍历到较大容量背包时还可能再次放入相同物品，这是违反了物品只能放入一次的要求**；由于需要对背包容量从大到小进行遍历，此时**只能先遍历物品，再遍历背包**。如果先遍历背包，就会导致每种背包容量都只会放入一个物品。*对于背包容量的遍历顺序，在二维动态规划数组中，由于限制了物品选择选择范围，因此当前需要考虑的只是是否需要将当前物品放入背包中；而在一维动态规划数组中，相当于取消了物品选择范围的限制，每次都是从题目中给定的物品中选择，因此（如果从小到大遍历背包）可能存在小背包放入了物品后，大背包在此基础上又放入了相同的物品*。代码如下：
    ```C++
    #include <iostream>
    #include <vector>

    using namespace std;

    int main(){
        int m, n;
        cin >> m >> n;

        vector<int> cost(m);
        vector<int> value(m);
        for(int i = 0; i < m; i++){
            cin >> cost[i];
        }
        for(int i = 0; i < m; i++){
            cin >> value[i];
        }

        vector<int> dp(n + 1, 0);
        for(int i = 0; i < m; i++){
            // j >= cost[j]，确保更新公式正确；若该不等式不成立，则不需要更新
            for(int j = n; j >= cost[i]; j--){
                dp[j] = max(dp[j], dp[j - cost[i]] + value[i]);
            }
        }

        cout << dp.back() << endl;

        return 0;
    }
    ```

10.  目标和。题中给定数组为非负整数，可以将数组分为加 `+,-` 号的两个部分，即为 `left, right`。于是能够推出以下关系：1.`left + right = sum`; 2.`left - right = target`。从而可以得到：`left * 2 = (sum + target)`，即 `left = (sum + target) / 2`，其中 `left` 为整数。因此，可以将问题转换为背包问题，求给定背包容量为 `(sum + target) / 2` 时，能够将背包装满的种数。同时也可以通过回溯方式暴力求解组合的种数。
```C++
/* 方法 1：回溯：组合总和问题*/
class Solution{
private:
    int count;

    void backtracking(const vector<int>& nums, int startIndex, int target){
        if(target == 0){
            count++;
            // return;          // 不能在 target == 0 后直接返回，否则导致 left = 0 时，结果为 1（正确为 2）.
        }

        for(int i = 0; i < nums.size() && nums[i] <= target; i++){
            backtracking(nums, i + 1, target - nums[i]);
        }
    }

public:
    int findTargetSumWays(vector<int>& nums, int target){
        int sum = accumulate(nums.begin(), nums.end(), 0);
        if(abs(target) > sum) return 0;     // 数组为非负整数数组
        if((sum + target) % 2) return 0;    // 数组为非负整数数组
        int left = (sum + target) / 2;

        count = 0;
        sort(nums.begin(), nums.end());     // 组合时需要排序，剪枝
        backtracking(nums, 0, left);
        return count;
    }
}
/* 方法 2：动态规划：0-1 背包问题*/
class Solution{
    int findTargetSumWays(vector<int>& nums, int target){
        int sum = accumulate(nums.begin(), nums.end(), 0);
        // 需要通过 target 的绝对值来进行对比。
        // 一方面当 target 为负值，求绝对值大于 sum 时结果为 0；
        // 另一方面，如果在此处不通过绝对值进行判断会给后续初始化 vector 造成错误，不能初始化 vector 的元素个数为负值
        if(abs(target) > sum) return 0;
        if((sum + target) % 2) return 0;
        int left = (sum + target) / 2;

        // dp[i] += dp[i - nums[j]];    // i >= nums[j]，表示装满容量为 i 的背包的方式为装满容量为 i - nums[j] 的背包之和
        vector<int> dp(left + 1, 0);
        dp[0] = 1;                      // 装满容量为 0 的背包的方式初始化为 1 种
        for(int i = 0; i < nums.size(); i++){
            for(int j = left; j >= nums[i]; j--){
                dp[j] += dp[j - nums[i]];
            }
        }

        return dp.back();
    }
}
```
11. 一和零
```C++
class Solution {
public:
    int findMaxForm(vector<string>& strs, int m, int n) {
        // dp[i][j] 表示背包在 '1' 和 '0' 的维度上容量为 i 和 j 时子集中元素最多的个数
        // dp[i][j] = max(dp[i][j], dp[i - x][j - y] + 1)， 其中 x 和 y 分别表示 strs 中的元素 str 包含的 `1` 和 `0` 个数
        // 因为此时求的是子集元素最多的数量，不是组合数量，因此动态规划转换关系不是累加关系
        vector<vector<int>> dp(m + 1, vector<int>(n + 1, 0));
        for(int i = 0; i < strs.size(); i++){
            int x = 0;
            int y = 0;
            for(int j = 0; j < strs[i].size(); j++){
                if(strs[i][j] == '1') x++;
                else y++;
            }

            // 相当于遍历背包容量，只不过在此处需要从两个维度上进行遍历
            for(int u = n; u >= x; u--){
                for(int v = m; v >= y; v--){
                    dp[v][u] = max(dp[v][u], dp[v - y][u - x] + 1);
                }
            }
        }

        return dp[m][n];
    }
};
```
12. 完全背包问题。在 0-1 背包基础上，从每件物品只能放入背包中一次变为多次。在 0-1 背包问题中，需要先遍历物品，再遍历背包。而且要求遍历背包的方式是从大到下：
```C++
for(int i = 0; i < weight.size(); i++){
    for(int j = bagsize; j >= weight[i]; j--){
        dp[j] += dp[j - weight[i]];
    }
}
```
而在完全背包问题中，由于没有物品放置次数限制，因而也就没有遍历背包时从大到小顺序的要求。反而，需要顾及到重复放置的要求，遍历背包要从小到大的方式进行。此时，如果是需要求装满背包的最大重量，则遍历背包和物品的次序没有要求。而如果是装满背包的方式有多少种，则需要注意它们之间存在次序要求。
```C++
// 先便利背包方式
```

```C++
public:
    int rob(vector<int>& nums) {
        int maxNum = INT_MIN;
        if(nums.size() < 4){
            for(int i = 0; i < nums.size(); i++) maxNum = max(nums[i], maxNum);
        }else if(nums.size() == 4){
            maxNum = max(nums[0] + nums[2], nums[1] + nums[3]);
        }else{
            vector<int> dp(nums.size() - 3, 0);
            // 第一家和最后一家不能同时偷盗：
            // 1. 如果要偷盗第一家，则相当于将最终元素设在了倒数第二个，起始元素设在了第三个
            int first, end, mid;
            dp[0] = nums[2];
            dp[1] = max(nums[2], nums[3]);
            for(int i = 2; i < dp.size(); i++){
                dp[i] = max(dp[i - 1], dp[i - 2] + nums[i + 2]);
            }
            first = dp.back() + nums[0];
            // 2. 如果要偷盗最后一家，则相当于将最终元素设在了倒数第三个，起始元素设在了第二个
            dp = vector<int> (nums.size() - 3, 0);
            dp[0] = nums[1];
            dp[1] = max(nums[1], nums[2]);
            for(int i = 2; i < dp.size(); i++){
                dp[i] = max(dp[i - 1], dp[i - 2] + nums[i + 1]);
            }
            end = dp.back() + nums.back();
            // 3. 第一家和最后一家都不偷盗，则相当于将起始元素设在了第二个，最终元素设在了倒数第二个
            dp = vector<int> (nums.size() - 2, 0);
            dp[0] = nums[1];
            dp[1] = max(nums[1], nums[2]);
            for(int i = 2; i < dp.size(); i++){
                dp[i] = max(dp[i - 1], dp[i - 2] + nums[i + 1]);
            }
            mid = dp.back();
            
            maxNum = max(first, end);
            maxNum = max(maxNum, mid);
        }
        

        return maxNum;
    }
```

```C++
class Solution{
public:
    int rob(TreeNode* root){
        if(!root) return 0;
        // 1. 盗取当前节点
        int left = 0, right = 0;        // 在求最值的过程中，需要注意初始化值对最终结果有无影响 
        if(root->left) left = rob(root->left->left) + rob(root->left->right);

        if(root->left) noLeft = rob(root->left);
        if(root->right) noRight = rob(root->right);
```

```C++
        // i - 1 处是否持有股票，i 处是否持有股票，于是：
        // 通过 dp[i][0] 和 dp[i][1] 来分别表示当前 i 持有和卖出的最大价值
        // 则动态规划递推公式为：dp[i][0] = max(dp[i - 1][0], dp[i - 1][1] - prices[i]), dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] + prices[i]);
        vector<vector<int>> dp(prices.size(), vector<int>(2, 0));
        // 初始化动态规划的开始位置，根据下标含义：
        dp[0][0] = -prices[0];
        dp[0][1] = 0;
        for(int i = 1; i < prices.size(); i++){
            // 因为只能买卖一次，所以上述关系需要更改为：
            dp[i][0] = max(dp[i - 1][0], dp[i - 1][1] - prices[i]);
            dp[i][1] = max(dp[i - 1][1], dp[i - 1][0] + prices[i]);
        }

        // 通过动态规划解题时，本题与通过二叉树表示的打家劫舍问题的处理方法类似，每个位置都有多种情况需要讨论。不是说最后答案为多个值，而是最终答案需要在这多种情况对应的值中选取。
        return max(dp.back()[0], dp.back()[1]);
    }
```

26. 115.不同子序列。与 1143.最长公共子序列的相同点，都是考虑在一个范围内的情况（因为两者都不要求元素在字符串中连续），而不是特定位置（结束位置）。但在当前问题中需要注意的点是，**转换关系中不使用当前位置仍然能够包含所规定区间字符串的情况**。
```C++
/* 方法1：回溯方法，相当于暴力解法，超时 */
class Solution {
private:
    int count;

    void backtracking(const string& s, const string& t, int startIndex, int targetIndex){
        if(targetIndex == t.size()){
            count++;
            return;
        }

        for(int i = startIndex; i < s.size(); i++){
            if(s[i] == t[targetIndex]){
                backtracking(s, t, i + 1, targetIndex + 1);
            }
        }
    }

public:
    int numDistinct(string s, string t) {
        count = 0;
        backtracking(s, t, 0, 0);
        return count;
    }
};
/* 方法2：动态规划 */
class Solution {
public:
    int numDistinct(string s, string t) {
        // dp[i + 1][j + 1] 表示在 s 的 0~i 范围内包含 t 的 0~j 区间所表示字符串的个数
        // 则转换关系是: 当 s[i] == t[j] 时，dp[i][j] = dp[i - 1][j - 1](需要用到 s[i]) + dp[i - 1][j](不需要用到 s[i])
        //               当 s[i] != t[j] 时，dp[i][j] = dp[i - 1][j](不能用 s[i])
        // 为处理超出 int 的表示范围，将元素类型定义为 uint64_t
        vector<vector<uint64_t>> dp(s.size() + 1, vector<uint64_t>(t.size() + 1, 0));
        // 初始化，如果将起始位置内容放在动态递推处理过程中一起初始化，则会导致：
        // 由于 dp 初始时元素全为 0，且在递推关系中没有一个常量来提供累加（增加）的因子
        // 因此，最终导致元素全为 0
        // s 在 0~i 范围内包含空字符串的个数
        for(int i = 0; i <= s.size(); i++) dp[i][0] = 1;
        // 空字符串包含 t 的 ）0~j 区间所表示字符串的个数，其实下面内容可以省去
        // 它在 dp 整体元素的初始过程中已完成
        for(int j = 1; j <= t.size(); j++) dp[0][j] = 0;

        // 动态规划递推更新
        for(int i = 1; i <= s.size(); i++){
            for(int j = 1; j <= t.size(); j++){
                if(s[i - 1] == t[j - 1]) dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j];
                else dp[i][j] = dp[i - 1][j];
            }
        }

        return dp.back().back();
    }
};
```

```C++
class Solution {
public:
    int minDistance(string word1, string word2) {
        // 本质上是求最长公共子序列长度，因此：
        // dp[i][j] 表示在字符串 s 的 0~i - 1 区间内与字符串 t 的 0~j - 1 区间内的最长公共子序列长度
        // 转换关系：当 s[i - 1] == t[j - 1] 时，dp[i] = dp[i - 1][j - 1] + 1; 其他 dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
        // 初始化可以和动态转换更新一起
        vector<vector<int>> dp(word1.size() + 1, vector<int>(word2.size() + 1, 0));
        for(int i = 1; i <= word1.size(); i++){
            for(int j = 1; j <= word2.size(); j++){
                if(word1[i - 1] == word2[j - 1]) dp[i][j] = dp[i - 1][j - 1] + 1;
                else dp[i][j] = max(dp[i - 1][j], dp[i][j - 1]);
            }
        }

        return (word1.size() + word2.size() - dp.back().back() * 2);
        // return dp.back().back();
    }

/* 方法2：动态规划-动态规划数组中元素值即表示删除操作数，通过考虑每个区间所需的删除操作和转换关系得出最后结果 */
class Solution {
public:
    int minDistance(string word1, string word2) {
        // dp[i][j] 表示在 word1 的区间 0~i - 1 和 word2 的区间 0~j - 1 上，使两者一致所需的最小删除步数
        vector<vector<int>> dp(word1.size() + 1, vector<int>(word2.size() + 1, 0));
        // 转换关系：当 word1[i - 1] == word[j - 1] 时 dp[i][j] = dp[i - 1][j - 1];
        //          当 word1[i - 1] != word[j - 1] 时 dp[i][j] = min({dp[i - 1][j] + 1, dp[i][j - 1] + 1, dp[i - 1][j - 1] + 2})
        // 初始化，dp[0][j] = j; dp[i][0] = i;
        for(int i = 0; i <= word1.size(); i++) dp[i][0] = i;
        for(int j = 0; j <= word2.size(); j++) dp[0][j] = j;

        for(int i = 1; i <= word1.size(); i++){
            for(int j = 1; j <= word2.size(); j++){
                if(word1[i - 1] == word2[j - 1]) dp[i][j] = dp[i - 1][j - 1];
                else dp[i][j] = min({dp[i - 1][j] + 1, dp[i][j - 1] + 1, dp[i - 1][j - 1] + 2});
            }
        }

        return dp.back().back();
    }
```

29. 回文子串。两种方法：一是通过动态规划，与其他动态规划直接将数组元素定义为目标结果（直接或间接）不同，在统计回文子串个数时，需要结合回文串的特性进行动态规划才好推出转换关系。二是通过双指针的方式，以字符串中每个元素为回文串中心，向两边扩展来统计个数。需要注意的点是，**回文串中心具有两种情况，一是中心具有两个元素，而是中心只有一个元素。因此统计一个元素为中心的回文子串个数时也具有两种情况**。
```C++
/* 方式1：动态规划 */
class Solution{
public:
    int countSubstrings(string s){
        // dp[i][j] 表示 i ~ j 区间所表示的子串是否为回文串
        // 转换关系是：当 s[i] != s[j] 时，dp[i][j] = false; 
        // 当 s[i - 1] == s[j - 1] 时，if(dp[i + 1][j - 1]) dp[i][j] = true;

        // 初始化
        vector<vector<bool>> dp(s.size(), vector<bool>(s.size(), false));

        // 根据上述转换关系，需要从左下往右上遍历
        int res = 0;
        for(int i = s.size() - 1; i >= 0; i--){
            // j 是大于等于 i 的
            // 与 for(int j = 0; j < s.size(); j++) if(j >= i && ...) 是等价的，
            // 但这种方式更好理解遍历顺序是从左下到右上的
            for(int j = i; j < s.size(); j++){
                if(s[i] == s[j]){
                    // 当 i == j 是，单个元素是回文串
                    if(i == j) dp[i][j] = true;
                    // 当 i 和 j 只相差 1，即 j - i == 1 时，
                    // 此时 i + 1 > j - 1，不满足 j >= i 的条件，不能使用动态转换关系公式
                    else if(j - i == 1) dp[i][j] = true;
                    else if(dp[i + 1][j - 1]) dp[i][j] = true;
                }
                if(dp[i][j]) res++;
            }
        }
        return res;
    }
};
/* 方式2：双指针 */
class Solution {
private:
    // 双指针，通过回文串从中间向两边扩充的方式进行计数
    // 当字符串元素个数为偶数时，中间元素具有两个；奇数时，中间元素只有一个
    int  extendCount(const string& s, int mid1, int mid2, int end){
        int count = 0;
        while(mid1 >= 0 && mid2 < end && s[mid1] == s[mid2]){
            mid1--;
            mid2++;
            count++;
        }
        return count;
    }

public:
    int countSubstrings(string s) {
        // 通过以 s 中每个元素作为回文串中心的方式统计每个元素为中心时的回文串个数
        int res = 0;
        for(int i = 0; i < s.size(); i++){
            res += extendCount(s, i, i, s.size());
            res += extendCount(s, i, i + 1, s.size());
        }
        return res;
    }
};
```

30. 最长回文子序列。子序列问题，可以在基础字符串中取出不连续，但是顺序关系不变的元素组成子串来形成回文串。\
考虑要求是子串时，最长回文子串问题的动态规划解法可以是：动态规划数组 `dp[i][j]` 表示以 `i, j` **为结尾**的子串是否为回文串，然后统计每个回文串的长度，记录最大值信息。\
回到本题。要求是子序列，则需要将动态数组 `dp[i][j]` 的意义解释为在 `i ~ j` 区间内最长回文子序列的长度。于是可以得到转换关系。但需要注意的点是：当 `s[i] != s[j]` 时，即新加入的两个元素不能使得子序列成为回文串，还可能从这两个元素中取出一个时能够组成回文串。
```C++
class Solution {
public:
    int longestPalindromeSubseq(string s) {
        // dp[i][j] 表示在区间 i ~ j 范围内最长的回文子序列长度
        // 转换关系：当 s[i] == s[j] 时，dp[i][j] = dp[i + 1][j - 1] + 2;
        //           当 s[i] != s[j] 时，dp[i][j] = max(dp[i][j - 1], dp[i + 1][j])
        vector<vector<int>> dp(s.size(), vector<int>(s.size(), 0));
        // 初始化
        // 从左下至右上的遍历顺序
        for(int i = s.size() - 1; i >= 0; i--){
            // 需要保证 j >= i
            for(int j = i; j < s.size(); j++){
                if(s[i] == s[j]){
                    if(i == j) dp[i][j] = 1;
                    else if(j - i == 1) dp[i][j] = 2;
                    else dp[i][j] = dp[i + 1][j - 1] + 2;
                }else{
                    // j - 1 < 0 or i + 1 >= s.size() 这两种情况都被 j >= i 的要求拦截在 s[i] == s[j] 处
                    dp[i][j] = max(dp[i][j - 1], dp[i + 1][j]);
                }
            }
        }

        return dp[0][s.size() - 1];
    }
};
```
