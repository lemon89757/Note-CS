1. 在分发饼干中主要注意的点：1. 采用贪心算法，取能够满足胃口的最小饼干，因此**对胃口和饼干数组进行排序**，然后同时遍历饼干和胃口数组；2. **需要注意遍历循序**：2.1 如果从小到大遍历胃口和饼干：大饼干都满足不了小胃口就没有可满足任何胃口的饼干，因此需要先遍历饼干；如果先遍历胃口，就会出现问题：最小的饼干不能满足最小的胃口，导致最小的饼干也不能满足后序的胃口，最终结果为 0。2.2 如果从大到小遍历胃口和饼干，大饼干不能满足最大胃口，但是可能满足后序的小胃口，因此需要先遍历胃口再遍历饼干；如果先遍历饼干，可能出现问题：最大的饼干不能满足最大胃口，导致后序更小的饼干也不能满足最大的胃口，最终结果为 0。
```C++
class Solution{
public:
    /* 
     * g[i] 代表胃口值
     * s[i] 表示饼干值 
     */
    int findContentChildren(vector<int> &g, vector<int> &s){
        /* 从小到大遍历 */
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());

        int index   = 0;
        int ret     = 0;
        // 从小到大遍历，先遍历饼干
        for(int i = 0; i < s.size() && index < g.size(); i++){
            if(s[i] >= g[index]){
                ret++;
                index++;
            }
        }
        return ret;
    }

    int findContentChildren(vector<int> &g, vector<int> &s){
        /* 从大到小遍历 */
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());

        int index   = s.size() - 1;
        int ret     = 0;
        // 从大到小遍历，先遍历胃口
        for(int i = g.size() - 1; i >= 0 && index >= 0; i--){
            if(s[index] >= g[i]){
                ret++;
                index--;
            }
        }
        return ret;
    }
} 
```
2. 在本题中，摆动序列是指：连续数字之间的差严格地在正数和负数之间交替，则数字序列称为摆动序列。同时仅有一个或者两个**不等**元素的序列也视作摆动序列。要求数组作为摆动序列的最长子序列的长度，同时*允许从原始序列中删除一些*。碰到这种问题，最好还是画一下图，分析一下可以作为摆动元素需要满足什么条件，记当前节点 `i` 与 `i - 1` 和 `i + 1` 之间的差分别为：`prevDiff = nums[i] - nums[i - 1]; currDiff = nums[i + 1] - nums[i]`，于是可以推出（上述提示说从原始序列中删除一些，其实不需要删除，误导人的）：1. currDiff > 0 && prevDiff < 0; 2. currDiff < 0 && prevDiff > 0; 这两种情况肯定是可以满足题目要求来作为摆动元素的，那么还有没有其他种情况呢？有的，例如 `1, 2, 2, 2, 1` 中子序列 `1, 2, 1` 是满足条件的（从原数组中选择满足条件并保持原有顺序关系元素即可，不需要真正地从原始数组中删除）。于是，可以推广到：在单调递增/递减区间的端点是可能作为摆动元素的，但是中间的点是不可以的。`1, 2, 2, 2, 3` 中 `2` 不能算作单调区间的端点。
```C++
/* 方法 1： 贪心，局部最优推全局最优 */
class Solution{
public:
    int wiggleMaxLength(vector<int>& nums){
        if(nums.size() <= 1) return nums.size();
        int prevDiff = 0;
        int currDiff = 0;
        int ret      = 1;   // 考虑到 2 不同个元素也能算作摆动序列，默认最右端的元素是符合条件的
        // 同理，遍历操作会使第一个元素也是摆动元素
        for(int i = 0; i < nums.size() - 1; i++){
            currDiff = nums[i + 1] - nums[i];
            if(prevDiff >= 0 && currDiff < 0 || prevDiff <= 0 && currDiff > 0){
                ret++;
                prevDiff = currDiff;
            }
        }
        return ret;
    }
};
```

3. 本题的关键在于：**不能让“连续和”为负数的时候加上下一个元素，而不是不让“连续和”加上一个负数**。贪心的思路为局部最优：**当前“连续和”为负数的时候立刻放弃，从下一个元素重新计算“连续和”。因为负数加上下一个元素时，“连续和”只会越来越小**。从而推出全局最优：选取最大“连续和”。
4. 买卖股票的最佳时机II：获取最大利润可以这样考虑，*将最终利润分解为每天为单位的维度*，而不是从 0 天到第 3 天整体去考虑（举例）。当天的价格比前一天的价格高，表示取得了利润，同时可以由**局部最优推得全局最优**：即只要当前取得了利润就累加起来即可。需要注意的是：**想要获得利润至少要两天为一个交易单元**。
