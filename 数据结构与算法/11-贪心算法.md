1. 在分发饼干中主要注意的点：1. 采用贪心算法，取能够满足胃口的最小饼干，因此**对胃口和饼干数组进行排序**，然后同时遍历饼干和胃口数组；2. **需要注意遍历循序**：2.1 如果从小到大遍历胃口和饼干：大饼干都满足不了小胃口就没有可满足任何胃口的饼干，因此需要先遍历饼干；如果先遍历胃口，就会出现问题：最小的饼干不能满足最小的胃口，导致最小的饼干也不能满足后序的胃口，最终结果为 0。2.2 如果从大到小遍历胃口和饼干，大饼干不能满足最大胃口，但是可能满足后序的小胃口，因此需要先遍历胃口再遍历饼干；如果先遍历饼干，可能出现问题：最大的饼干不能满足最大胃口，导致后序更小的饼干也不能满足最大的胃口，最终结果为 0。
```C++
class Solution{
public:
    /* 
     * g[i] 代表胃口值
     * s[i] 表示饼干值 
     */
    int findContentChildren(vector<int> &g, vector<int> &s){
        /* 从小到大遍历 */
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());

        int index   = 0;
        int ret     = 0;
        // 从小到大遍历，先遍历饼干
        for(int i = 0; i < s.size() && index < g.size(); i++){
            if(s[i] >= g[index]){
                ret++;
                index++;
            }
        }
        return ret;
    }

    int findContentChildren(vector<int> &g, vector<int> &s){
        /* 从大到小遍历 */
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());

        int index   = s.size() - 1;
        int ret     = 0;
        // 从大到小遍历，先遍历胃口
        for(int i = g.size() - 1; i >= 0 && index >= 0; i--){
            if(s[index] >= g[i]){
                ret++;
                index--;
            }
        }
        return ret;
    }
} 
```
2. 在本题中，摆动序列是指：连续数字之间的差严格地在正数和负数之间交替，则数字序列称为摆动序列。同时仅有一个或者两个**不等**元素的序列也视作摆动序列。要求数组作为摆动序列的最长子序列的长度，同时*允许从原始序列中删除一些*。碰到这种问题，最好还是画一下图，分析一下可以作为摆动元素需要满足什么条件，记当前节点 `i` 与 `i - 1` 和 `i + 1` 之间的差分别为：`prevDiff = nums[i] - nums[i - 1]; currDiff = nums[i + 1] - nums[i]`，于是可以推出（上述提示说从原始序列中删除一些，其实不需要删除，误导人的）：1. currDiff > 0 && prevDiff < 0; 2. currDiff < 0 && prevDiff > 0; 这两种情况肯定是可以满足题目要求来作为摆动元素的，那么还有没有其他种情况呢？有的，例如 `1, 2, 2, 2, 1` 中子序列 `1, 2, 1` 是满足条件的（从原数组中选择满足条件并保持原有顺序关系元素即可，不需要真正地从原始数组中删除）。于是，可以推广到：在单调递增/递减区间的端点是可能作为摆动元素的，但是中间的点是不可以的。`1, 2, 2, 2, 3` 中 `2` 不能算作单调区间的端点。
```C++
/* 方法 1： 贪心，局部最优推全局最优 */
class Solution{
public:
    int wiggleMaxLength(vector<int>& nums){
        if(nums.size() <= 1) return nums.size();
        int prevDiff = 0;
        int currDiff = 0;
        int ret      = 1;   // 考虑到 2 不同个元素也能算作摆动序列，默认最右端的元素是符合条件的
        // 同理，遍历操作会使第一个元素也是摆动元素
        for(int i = 0; i < nums.size() - 1; i++){
            currDiff = nums[i + 1] - nums[i];
            if(prevDiff >= 0 && currDiff < 0 || prevDiff <= 0 && currDiff > 0){
                ret++;
                prevDiff = currDiff;
            }
        }
        return ret;
    }
};
```

3. 本题的关键在于：**不能让“连续和”为负数的时候加上下一个元素，而不是不让“连续和”加上一个负数**。贪心的思路为局部最优：**当前“连续和”为负数的时候立刻放弃，从下一个元素重新计算“连续和”。因为负数加上下一个元素时，“连续和”只会越来越小**。从而推出全局最优：选取最大“连续和”。
4. 买卖股票的最佳时机II：获取最大利润可以这样考虑，*将最终利润分解为每天为单位的维度*，而不是从 0 天到第 3 天整体去考虑（举例）。当天的价格比前一天的价格高，表示取得了利润，同时可以由**局部最优推得全局最优**：即只要当前取得了利润就累加起来即可。需要注意的是：**想要获得利润至少要两天为一个交易单元**。
5. 在跳跃游戏中，不应该关注如何跳到某一个点，而应该关注目标点是否在能跳到的**范围内**。在跳跃游戏 I 中，只需要遍历数组中的值，同时进行判断允许跳跃的范围内是否存在数组最后一个位置即可；而在跳跃游戏 II 中，需要考虑使用最少步数跳到数组的最后一个位置（题中假设能够跳到目标点），这也是从跳跃范围来考虑：当前点和跳跃范围和下一点的跳跃范围，贪心地选取最大的跳跃范围，即可在最少的步数完成跳跃。
```C++
/* 跳跃游戏II */
class Sulotion{
public:
    /* 方法 1： 需要对目标位置进行特殊处理 */
    int jump(vector<int>& nums){
        // curDistance 从 0 开始，初始位置时就需要给步数加 1
        int curDistance = 0;
        int nextDistance = 0;
        int ret = 0;
        for(int i = 0; i < nums.size(); i++){
            nextDistance = max(nextDistance, i + nums[i]);
            if(i == curDistance){
                curDistance = nextDistance;
                // 当前位置是最后一个位置时，直接退出，不需要给 ret++
                if(i == nums.size() - 1) break;
                ret++;
            }
        }
        return ret;
    }

    /* 方法 2： 不需要对目标位置进行特殊处理 */
    int jump(vector<int>& nums){
        // curDistance 从 0 开始，初始位置时就需要给步数加 1
        int curDistance = 0;
        int nextDistance = 0;
        int ret = 0;
        // 由于题中给出：总是能够到达目标位置的前提条件
        // 因此给 i 的遍历上限设置到最后一个位置的前一位置
        // 此时无需给最后到达的是目标位置做特殊处理
        for(int i = 0; i < nums.size() - 1; i++){
            nextDistance = max(nextDistance, i + nums[i]);
            if(i == curDistance){
                curDistance = nextDistance;
                ret++;
            }
        }
        return ret;
    }
}
```
6. 贪心算法，第一次贪心：先保证数组中**绝对值最大**的数为正数；第二次贪心：当数组中元素全部为正数时，将**绝对值最小，即数值最小的数**取负值。最后得到的结果为 K 次取反后的最大化数组和。也可以，方法 2：**利用最小堆**，不断地给堆顶元素（即最小值）取负值，然后再将其添加到堆中。也是一种贪心方式：只对最小值取负值，能得到全局最优的最大数组和。
```C++
/* 方法 1 */
class Solution{
private:
    static bool cmp(int a, int b){
        return abs(a) > abs(b);
    }

public:
    int largestSumAfterKNegations(vector<int>& nums, int k){
        int res = 0;
        // 按绝对值从大到小排序
        sort(nums.begin(), nums.end(), cmp);
        for(int i = 0; i < nums.size(); i++){
            if(nums[i] < 0 && k > 0){
                // 先给绝对值大的负数取反
                nums[i] *= -1;
                k--;
            }
        }

        // 如果 k 还大于 0，给绝对值最小的数取反
        if(k % 2) nums[nums.size() - 1] *= -1;
        // 求和
        for(int i = 0; i < nums.size(); i++){
            res += nums[i];
        }

        return res;
    }
}

/* 方法 2 */
class Solution{
public:
    int largestSumAfterKNegations(vector<int>& nums, int k){
        // 小顶堆
        priority_queue<int, vector<int>, greater<int>> minHeap;
        for(int num : nums) minHeap.push(num);
        
        int temp;
        while(k--){
            temp = minHeap.top();
            minHeap.pop();
            temp *= -1;
            minHeap.push(temp);
        }

        int res = 0;
        while(!minHeap.empty()){
            res += minHeap.top();
            minHeap.pop();
        }

        return res;
    }
}
```
