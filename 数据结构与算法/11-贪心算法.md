1. 在分发饼干中主要注意的点：1. 采用贪心算法，取能够满足胃口的最小饼干，因此**对胃口和饼干数组进行排序**，然后同时遍历饼干和胃口数组；2. **需要注意遍历循序**：2.1 如果从小到大遍历胃口和饼干：大饼干都满足不了小胃口就没有可满足任何胃口的饼干，因此需要先遍历饼干；如果先遍历胃口，就会出现问题：最小的饼干不能满足最小的胃口，导致最小的饼干也不能满足后序的胃口，最终结果为 0。2.2 如果从大到小遍历胃口和饼干，大饼干不能满足最大胃口，但是可能满足后序的小胃口，因此需要先遍历胃口再遍历饼干；如果先遍历饼干，可能出现问题：最大的饼干不能满足最大胃口，导致后序更小的饼干也不能满足最大的胃口，最终结果为 0。
```C++
class Solution{
public:
    /* 
     * g[i] 代表胃口值
     * s[i] 表示饼干值 
     */
    int findContentChildren(vector<int> &g, vector<int> &s){
        /* 从小到大遍历 */
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());

        int index   = 0;
        int ret     = 0;
        // 从小到大遍历，先遍历饼干
        for(int i = 0; i < s.size() && index < g.size(); i++){
            if(s[i] >= g[index]){
                ret++;
                index++;
            }
        }
        return ret;
    }

    int findContentChildren(vector<int> &g, vector<int> &s){
        /* 从大到小遍历 */
        sort(g.begin(), g.end());
        sort(s.begin(), s.end());

        int index   = s.size() - 1;
        int ret     = 0;
        // 从大到小遍历，先遍历胃口
        for(int i = g.size() - 1; i >= 0 && index >= 0; i--){
            if(s[index] >= g[i]){
                ret++;
                index--;
            }
        }
        return ret;
    }
}
```

2. 在本题中，摆动序列是指：连续数字之间的差严格地在正数和负数之间交替，则数字序列称为摆动序列。同时仅有一个或者两个**不等**元素的序列也视作摆动序列。要求数组作为摆动序列的最长子序列的长度，同时*允许从原始序列中删除一些*。碰到这种问题，最好还是画一下图，分析一下可以作为摆动元素需要满足什么条件，记当前节点 `i` 与 `i - 1` 和 `i + 1` 之间的差分别为：`prevDiff = nums[i] - nums[i - 1]; currDiff = nums[i + 1] - nums[i]`，于是可以推出（上述提示说从原始序列中删除一些，其实不需要删除，误导人的）：1. currDiff > 0 && prevDiff < 0; 2. currDiff < 0 && prevDiff > 0; 这两种情况肯定是可以满足题目要求来作为摆动元素的，那么还有没有其他种情况呢？有的，例如 `1, 2, 2, 2, 1` 中子序列 `1, 2, 1` 是满足条件的（从原数组中选择满足条件并保持原有顺序关系元素即可，不需要真正地从原始数组中删除）。于是，可以推广到：在单调递增/递减区间的端点是可能作为摆动元素的，但是中间的点是不可以的。`1, 2, 2, 2, 3` 中 `2` 不能算作单调区间的端点。

```C++
public:
    int wiggleMaxLength(vector<int>& nums){
        if(nums.size() <= 1) return nums.size();
        int prevDiff = 0;
        int currDiff = 0;
        int ret      = 1;   // 考虑到 2 不同个元素也能算作摆动序列，默认最右端的元素是符合条件的

        for(int i = 0; i < nums.size() - 1; i++){
            currDiff = nums[i + 1] - nums[i];
            if(prevDiff >= 0 && currDiff < 0 || prevDiff <= 0 && currDiff > 0){
                ret++;
                prevDiff = currDiff;
            }
        }
        return ret;
    }
```

3. 本题的关键在于：**不能让“连续和”为负数的时候加上下一个元素，而不是不让“连续和”加上一个负数**。贪心的思路为局部最优：**当前“连续和”为负数的时候立刻放弃，从下一个元素重新计算“连续和”。因为负数加上下一个元素时，“连续和”只会越来越小**。从而推出全局最优：选取最大“连续和”。
4. 买卖股票的最佳时机II：获取最大利润可以这样考虑，*将最终利润分解为每天为单位的维度*，而不是从 0 天到第 3 天整体去考虑（举例）。当天的价格比前一天的价格高，表示取得了利润，同时可以由**局部最优推得全局最优**：即只要当前取得了利润就累加起来即可。需要注意的是：**想要获得利润至少要两天为一个交易单元**。
5. 在跳跃游戏中，不应该关注如何跳到某一个点，而应该关注目标点是否在能跳到的**范围内**。在跳跃游戏 I 中，只需要遍历数组中的值，同时进行判断允许跳跃的范围内是否存在数组最后一个位置即可；而在跳跃游戏 II 中，需要考虑使用最少步数跳到数组的最后一个位置（题中假设能够跳到目标点），这也是从跳跃范围来考虑：当前点和跳跃范围和下一点的跳跃范围，贪心地选取最大的跳跃范围，即可在最少的步数完成跳跃。
```C++
/* 跳跃游戏II */
class Sulotion{
public:
    /* 方法 1： 需要对目标位置进行特殊处理 */
    int jump(vector<int>& nums){
        // curDistance 从 0 开始，初始位置时就需要给步数加 1
        int curDistance = 0;
        int nextDistance = 0;
        int ret = 0;
        for(int i = 0; i < nums.size(); i++){
            nextDistance = max(nextDistance, i + nums[i]);
            if(i == curDistance){
                curDistance = nextDistance;
                // 当前位置是最后一个位置时，直接退出，不需要给 ret++
                if(i == nums.size() - 1) break;
                ret++;
            }
        }
        return ret;
    }

    /* 方法 2： 不需要对目标位置进行特殊处理 */
    int jump(vector<int>& nums){
        // curDistance 从 0 开始，初始位置时就需要给步数加 1
        int curDistance = 0;
        int nextDistance = 0;
        int ret = 0;
        // 由于题中给出：总是能够到达目标位置的前提条件
        // 因此给 i 的遍历上限设置到最后一个位置的前一位置
        // 此时无需给最后到达的是目标位置做特殊处理
        for(int i = 0; i < nums.size() - 1; i++){
            nextDistance = max(nextDistance, i + nums[i]);
            if(i == curDistance){
                curDistance = nextDistance;
                ret++;
            }
        }
        return ret;
    }
}
```
6. 贪心算法，第一次贪心：先保证数组中**绝对值最大**的数为正数；第二次贪心：当数组中元素全部为正数时，将**绝对值最小，即数值最小的数**取负值。最后得到的结果为 K 次取反后的最大化数组和。也可以，方法 2：**利用最小堆**，不断地给堆顶元素（即最小值）取负值，然后再将其添加到堆中。也是一种贪心方式：只对最小值取负值，能得到全局最优的最大数组和。
```C++
/* 方法 1 */
class Solution{
private:
    static bool cmp(int a, int b){
        return abs(a) > abs(b);
    }

public:
    int largestSumAfterKNegations(vector<int>& nums, int k){
        int res = 0;
        // 按绝对值从大到小排序
        sort(nums.begin(), nums.end(), cmp);
        for(int i = 0; i < nums.size(); i++){
            if(nums[i] < 0 && k > 0){
                // 先给绝对值大的负数取反
                nums[i] *= -1;
                k--;
            }
        }

        // 如果 k 还大于 0，给绝对值最小的数取反
        if(k % 2) nums[nums.size() - 1] *= -1;
        // 求和
        for(int i = 0; i < nums.size(); i++){
            res += nums[i];
        }

        return res;
    }
}

/* 方法 2 */
class Solution{
public:
    int largestSumAfterKNegations(vector<int>& nums, int k){
        // 小顶堆
        priority_queue<int, vector<int>, greater<int>> minHeap;
        for(int num : nums) minHeap.push(num);
        
        int temp;
        while(k--){
            temp = minHeap.top();
            minHeap.pop();
            temp *= -1;
            minHeap.push(temp);
        }

        int res = 0;
        while(!minHeap.empty()){
            res += minHeap.top();
            minHeap.pop();
        }

        return res;
    }
}
```
7. *方法 1（贪心）*：类似于 53.最大子数组和，但是当前是**在环形数组上求最大子数组和**；*方法 2（技巧型）*：统计数组和以及在求和过程中遇到的最小剩余油量，可以分为三种情况：a. 当数组和小于 0 时，表示无论如何都不能跑一圈；b. 数组和大于等于 0，同时最小剩余油量大于等于 0，表示可以从 0 位置作为起始位置跑完一圈而不会出现少油的情况；c. 数组和大于等于 0，最小剩余油量小于 0，此时需要倒序遍历数组，直到将缺少的油量填补到大于 0；方*法 3（贪心）*：类似于方法 1，统计子数组和、数组和；*方法 4（暴力搜索）*：超时。

```C++
/* 方法 1：需要将数组当作是环形数组进行处理 */
class Solution{
public:
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost){
        int gasSum = accumulate(gas.begin(), gas.end(), 0);
        int costSum = accumulate(cost.begin(), cost.end(), 0);
        if(gasSum < costSum ) return -1;

        int len = gas.size();
        // start 从 -1 开始，以满足答案为 0 的情况
        int res = 0, start = -1, maxSubSum = 0, subSum = 0;
        // 由于需要将数组当作是环形数组，因此 i 的范围从 [0, len) 变为 [0, 2 * len)
        for(int i = 0; i < 2 * len; i++){
            subSum += gas[i % len] - cost[i % len];
            if(subSum > maxSubSum){
                maxSubSum = subSum;
                // start 记录的是子区间和小于 0 的最后一个元素的位置
                // 因此起始位置是 start + 1
                res = (start + 1) % len;
            }
            if(subSum < 0){
                subSum = 0;
                start = i;
            }
        }
        return res;
    }
}
/* 方法 2 */
class Solution{
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost){
        int len = gas.size();
        int totalSum = 0, minSubSum = 0;
        for(int i = 0; i < len; i++){
            totalSum += gas[i] - cost[i];
            if(totalSum < minSubSum) minSubSum = totalSum;
        }

        if(totalSum < 0) return -1;
        if(minSubSum == 0) return 0;
        for(int i = len - 1; i >= 0; i++){
            minSubSum += gas[i] - cost[i];
            if(minSubSum >= 0) return i;
        }

        return -1;
    }
}

class Solution{
    int canCompleteCircuit(vector<int>& gas, vector<int>& cost){
        int len = gas.size();
        for(int i = 0; i < len; i++){
            int index = (i + 1) % len;
            int sum = gas[i] - cost[i];
            while(sum >= 0 && index != i){
                sum += gas[index] - cost[index];
                index = (index + 1) % len;
            }

            if(index == i && sum >= 0) return i;
        }
        return -1;
    }
}
```

8. 在分发糖果问题中，需要考虑的关键问题是：相邻两个孩子评分更高的孩子会获得更多的糖果。为了满足该要求，需要照顾到两个方向的大小关系要求。针对该要求：1. **一定是要确定一边后再确定另一边，如果两边一起考虑一定会顾此失彼**。2. 当从某一特定方向的遍历顺序考虑时，**当前位置的糖果数量是之前所有位置的递推结果**（类似于动态规划），因此当前位置的糖果数量与之前的所有位置相关。因此，不能在单一方向上遍历多次以完成糖果分配。3. 在第二个方向上进行糖果分配时，如果出现：`rating[i] > raing[i + 1]` 时，`candyVec[i]` 就有两个选择：`candyVec[i + 1] + 1` 和 `candyVec[i]`（第一次分配的数量）。**为了满足同时左右方向上的大小关系，取 `max(candyVec[i + 1] + 1, candyVec[i])`**。贪心，局部最优可以推出全局最优。另外，因为每个孩子都至少有一颗糖果，因此可以给糖果数组的元素都初始化为 1。
```C++
class Solution{
public:
    int candy(vector<int>& ratings){
        // 每个人最少都有一颗糖果，数组元素初始化为 1
        vector<int> count(ratings.size(), 1);
        // 从前向后遍历
        for(int i = 1; i < count.size(); i++){
            if(ratings[i] > rating[i - 1]) count[i] = count[i - 1] + 1;
        }
        // 再从后向前遍历
        for(int i = count.size() - 1; i >= 1; i--){
            if(ratings[i - 1] > ratings[i]) count[i - 1] = max(count[i] + 1, count[i - 1]);
        }
        // 求和
        int res = 0;
        for(int i = 0; i < count.size(); i++) res += count[i];

        return res;
    }
}
```

10. 与 135.分发糖果类似，该题也需要考虑两个维度以完成排序。同样的，如果每次对数组中的元素进行排序时需要考虑两个维度上的指标，会使得问题难以下手，容易顾了这头，忘了那头；容易满足当前元素的位置要求，又使得之前排完序的元素不符要求；或者在给当前元素排序时，不但需要从两个维度上照顾当前元素，还需要照顾到以排序的元素。这使得问题很难下手。**与 135.分发糖果类似，需要解决一个维度上的问题，再去解决另一个维度**。所谓把问题逐层分解为一个个容易解决的问题，从而把整体问题解决。不考虑对元素组进行修改来进行排序，因为对于每个元素确定其位置都需要从两个维度去考虑，又绕回了上述内容中。而且与 135.题不同的是，135.题中当前元素只与左右侧相邻的元素相关，元素整体之间存在着一个递推关系；而在本题中，当前元素最终位置的确定与所有元素相关，它们之间不存在递推关系，每个元素的最终位置需要从整体的层面出发来确定是很困难的。于是，习惯性地，类似于抓牌并在手中排序的过程，**从原有数组中选择一个元素将其插入到排好序的数组中以完成排序**。这时，可以发现：将已完成排序的部分与当前将要排序的元素进行对比，如果当前元素的身高比它们都要大：其插入的位置会对其后面的元素造成影响，而对前方的元素无影响，同时它们对当前元素 k 值无影响，因此当前元素需要在前面预留 k 个空位给大于等于 h 的元素；如果当前元素的身高比它们都要小：其插入的位置对它们都无影响，此时只需要关注当前元素的第二个指标即可。因此，**先按身高从大到小排序**。而当身高相等时，由于身高相等也会使 k 加 1，为使已排序部分满足题目要求，从而使整体满足要求，需要**当身高相等时，先插入 k 值更小的元素**：
```C++
/* 由于涉及频繁的插入操作： */
/* 方式 1：使用 vector 来保存排序好的数组，效率低 */
class Solution {
private:
    static bool cmp(vector<int>& a, vector<int>& b){
        // 注意 a[0] == b[0] 时，需要取 a[1] < b[1]
        if(a[0] == b[0]) return a[1] < b[1];
        return a[0] > b[0];
    }
public:
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        vector<vector<int>> res;
        sort(people.begin(), people.end(), cmp);
        // emplace_back 相当于给仅声明的变量 res 初始化了
        res.emplace_back(people[0]);
        for(int i = 1; i < people.size(); i++){
            res.insert(res.begin() + people[i][1], people[i]);
        }
        return res;
    }
};
/* 方式 2： 使用 list 来保存排序好的数组，效率高 */
class Solution {
private:
    static bool cmp(vector<int>& a, vector<int>& b){
        // 注意 a[0] == b[0] 时，需要取 a[1] < b[1]
        if(a[0] == b[0]) return a[1] < b[1];
        return a[0] > b[0];
    }
public:
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        sort(people.begin(), people.end(), cmp);
        // list 的底层实现是链表，插入效率比 vector 高得多
        list<vector<int>> que;
        for(int i = 0; i < people.size(); i++){
            int pos = people[i][1];
            list<vector<int>>::iterator it = que.begin();
            while(pos--){
                it++;
            }
            que.insert(it, people[i]);
        }
        return vector<vector<int>>(que.begin(), que.end());
    }
};
```

>[leetcode题解](https://leetcode.cn/problems/queue-reconstruction-by-height/solutions/486066/gen-ju-shen-gao-zhong-jian-dui-lie-by-leetcode-sol/)
```C++
class Solution {
public:
    vector<vector<int>> reconstructQueue(vector<vector<int>>& people) {
        // 按照 h 为第一关键字升序，k 为第二关键字降序进行排序
        sort(people.begin(), people.end(), [](const vector<int>& u, const vector<int>& v) {
            return u[0] < v[0] || (u[0] == v[0] && u[1] > v[1]);
        });
        int n = people.size();
        vector<vector<int>> ans(n);
        for (const vector<int>& person: people) {
            int spaces = person[1] + 1;
            for (int i = 0; i < n; ++i) {
                if (ans[i].empty()) {
                    --spaces;
                    if (!spaces) {
                        ans[i] = person;
                        break;
                    }
                }
            }
        }
        return ans;
    }
};
```

13. 划分字母区间：*不是回溯*，回溯更多的是求“数量”。而本题中带有“尽可能多”的字眼，应试试贪心。局部贪心：局部范围内的字符在该范围之外并没有在其他位置出现，从而满足尽可能多地对字符串进行分段。能够由局部贪心推出全局最优。**而“局部范围内的字符在该范围之外并没有在其他位置出现”可以表述为：当前位置为局部范围内所有字符出现的的最远位置**，因此遍历两边字符串，一遍用来记录字符出现的最远位置，第二遍用来进行分割。需要注意的是：**由于题中规定了字符串中字符数量、且元素之间连续分布（全是小写字母），因此使用数组来记录字符出现的最远位置比使用哈希表效率更高**。
