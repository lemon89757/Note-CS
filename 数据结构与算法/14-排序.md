# 排序
> [hello算法](https://www.hello-algo.com/chapter_sorting/)

排序算法通常基于**运行效率、就地性、稳定性、自适应性（利用输入数据已有的顺序信息来减少计算量，达到更优的效率，自适应排序算法的最佳时间复杂度通常优于平均时间复杂度）等**方面来对其进行评价。

## 选择排序
记数组长度为 `n`
- 基本思想：开启一个循环，每轮从未排序区间选择最小的元素，将其放到已排序区间的末尾。其中，未排序区间和已排序区间都是在原有的数组上，因此*具有原地性*。
- 流程：
  1. 初始状态下，所有元素未排序，即未排序区间为 `[0, n - 1]`；
  2. 选取区间 `[0, n - 1]` 中最小的元素，将其与索引 0 处的元素交换。完成后，数组前 1 元素已排序。
  3. 选取区间 `[1, n - 1]` 中的最小元素，将其与索引 1 处的元素交换。...
  4. 依次类推。经过 `n - 1` 轮交换后，数组前 `n - 1` 个元素已排序。仅剩的一个元素必定是最大元素，无需排序。数组排序完成。
- 特性：
  1. 时间复杂度：外循环共 `n - 1` 轮，第一轮的未排序区间长度为 `n`，最后一轮的未排序区间长度为 2，即各轮外循环分别包含 `n、n - 1、...、3、2` 轮内循环，求和为 $(n + 2)*(n - 1) / 2$。所以**时间复杂度为 `O(n^2)`**
  2. 非自适应排序
  3. 空间复杂度：`O(1)`
  4. 原地排序
  5. 非稳定排序：在元素交换过程中可能导致相对顺序发生改变，所以是非稳定排序。
- 代码示例：
```C++
void selectionSort(vector<int> &nums){
  int n = nums.size();
  // 外循环，未排序区间为 [i, n - 1]
  // 由于最后一个元素为最大值，不需要排序，故 i < n -1;
  for(int i = 0; i < n - 1; i++){
    int k = i;
    for(int j = i + 1; j < n; j++){
      if(nums[j] < nums[k]) k = j;
    }
    swap(nums[i], nums[k]);
  }
}
```

## 冒泡排序
记数组长度为 `n`
- 基本思想：通过连续地比较与交换相邻元素实现排序。这个过程就像气泡从底部升到顶部一样。
- 流程：
  1. 首先，对 `n` 个元素执行“冒泡”，将数组的最大元素交换至正确位置；
  2. 对剩余的 `n - 1` 个元素执行“冒泡”，将第二大元素交换至正确位置；
  3. 依此类推，经过 `n - 1` 轮“冒泡”后，前 `n - 1` 大的元素都被交换至正确位置；
  4. 仅剩的一个元素即为最小元素，无需排序。
- 特性：
  1. 时间复杂度：`O(n^2)`，各轮“冒泡”遍历的数组长度依次为 `n - 1、n - 2、...、2、1`，总和为 $(n - 1)*n/2$。在引入 `flag` 优化后，最佳时间复杂度可达到 `O(n)`。
  2. 自适应排序
  3. 空间复杂度为 `O(1)`
  4. 原地排序
  5. 稳定排序：在“冒泡”过程中遇到相等的元素不交换。
- 代码示例：
```C++
void bubbleSort(vector<int> &nums){
  for(int i = nums.size() - 1; i > 0; i--){
    for(int j = 0; j < i; j++){
      if(nums[j] > nums[j + 1]) swap(nums[j], nums[j + 1]);
    }
  }
}
```
如果某轮“冒泡”中没有执行任何交换操作，说明数组已经完成排序，可直接返回结果。因此，可以增加一个标志位 `flag` 来检测这种情况：
```C++
void bubbleSortWithFlag(vector<int> &nums){
  for(int i = nums.size(); i > 0; i--){
    bool flag = false;
    for(int j = 0; j < i; j++){
      if(nums[j] > nums[j + 1]){
        swap(nums[j], nums[j + 1]);
        flag = true;
      }
    }
    // 未交换任何元素，直接跳出
    if(!flag) break;
  }
}
```

## 插入排序
- 基本思想：工作原理与手动整理一副牌的过程非常相似。具体来说，在未排序区间中选择一个基准元素，将该元素与其左边已排序区间的元素逐一比较大小，并将该元素插入到正确位置。
- 流程：
  1. **初始状态下，数组的第一个元素已完成排序**；
  2. 选取第 2 个元素作为 `base`，将其插入到正确位置后，数组的前 2 个元素已经完成排序；
  3. 选取第 3 个元素作为 `base`，将其插入到正确位置后，数组的前 3 个元素已排序；
  4. 以此类推，在最后一轮中，选取最后一个元素作为 `base` ，将其插入到正确位置后，所有元素均已排序
- 特性
  1. 时间复杂度：`O(n^2)`。在最差情况下，每次插入操作分别需要循环 `n - 1、n - 2、...、2、1` 次，求和得到$(n - 1) * n / 2$，因此时间复杂度为 `O(n^2)`。
  2. 自适应排序：在遇到有序数据时，插入操作会提前终止。当输入数组完全有序时，插入排序达到最佳时间复杂度 `O(n)`。
  3. 空间复杂度：`O(1)`
  4. 原地排序
  5. 稳定排序：在插入操作过程中，会将元素插入到相等元素的右边，不会改变它们之间的顺序。
  6. **插入排序的优势**：
     1. 插入排序的时间复杂度为 `O(n^2)`，而快速排序的时间复杂度为 `O(nlogn)`。尽管插入排序的时间复杂度更高，**但在数据量较小的情况下，插入排序通常更快**。这个结论与线性查找和二分查找的适用情况的结论类似。快速排序这类 `O(nlogn)` 的算法属于基于分治策略的排序算法，往往包含更多单元计算操作。*而在数据量较小时，$n^2$ 和 $nlogn$ 的数值比较接近，复杂度不占主动地位，每轮中的单元操作数量起到决定性作用*。实际上，许多编程语言（eg: JAVA）的内置排序函数采用了插入排序，大致思路是：对于长数组，采用基于分治策略的排序算法，例如快速排序；对于短数组，直接使用插入排序。
     2. 虽然冒泡排序、选择排序和插入排序的时间复杂度都是 `O(n^2)`，但在实际情况中，**插入排序的使用频率显著高于冒泡排序和选择排序**，主要原因：1. 冒泡排序基于元素交换实现，需要借助一个临时变量，共涉及 3 个单元操作；而插入排序基于元素赋值实现，仅需一个单元操作。因此，*冒泡排序的计算开销通常比插入排序更高*。2. 选择排序在任何情况下的时间复杂度都是 `O(n^2)`。如果给定一组部分有序的数据，*插入排序通常比选择排序效率更高*。3. *选择排序不稳定，无法应用于多级排序*。
- 代码示例： 
```C++
void insertionSort(vector<int> &nums){
  for(int i = 1; i < nums.size(); i++){
    int base = nums[i], j = i - 1;
    while(j >= 0 && nums[j] > base){
      nums[j + 1] = nums[j];
      j--;
    }
    nums[j + 1] = base;
  }
}
```

## 快速排序
- 基本思想：是一种基于分治策略的排序算法，运行高效，应用广泛。快速排序的核心操作是“**哨兵划分**”，其目标是：选择数组中的某个元素作为“基准数”，将所有小于基准数的元素移到其左侧，而大于基准数的元素移到其右侧。（哨兵划分的实质是将一个较长数组的排序问题简化为两个较短数组的排序问题）
- 流程（哨兵划分流程）：
  1. 选取数组最左端元素作为基准数，初始化两个指针 `i` 和 `j` 分别指向数组的两端。
  2. 设置一个循环，在每轮中使用 `i/j` 分别寻找第一个比基准大/小的元素，然后交换这两个元素。
  3. 循环执行步骤2，直到 `i` 和 `j` 相遇时停止，最后将基准数交换至两个子数组的分界线。
- 流程（快速排序）：
  1. 在哨兵划分的基础上进行递归直到子数组长度为 1 时终止，从而完成整个数组的排序。
- 特性：
  1. 时间复杂度：`O(nlogn)`。在平均情况下，哨兵划分的递归层数为 `logn`，在每层中的总循环数为 `n`，总体使用 `O(nlogn)`。在最差情况下，每轮哨兵划分操作都将长度为 `n` 的数组划分为长度为 0 和 `n - 1` 的两个子数组，此时递归层数达到 n，每层中的循环数为 `n`，总体使用 `O(n^2)` 时间。
  2. 非自适应排序
  3. 空间复杂度：`O(n)`。在输入数组完全倒序的情况下，达到最差的递归深度 n，使用 `O(n)` 栈帧空间。排序操作都是在原数组上进行的，未借助额外数组。
  4. 非稳定排序：在哨兵最后一步，基准数可能会被交换至相等元素的右侧。
  5. 为什么快：
    *尽管快速排序的平均时间复杂度与归并排序、堆排序相同，但通常快速排序的效率更高*
     1. 出现最差情况的概率很低：虽然快速排序的最差时间复杂度为 `O(n^2)`，没有归并排序稳定，但在绝大多数情况下，快速排序能够在 `O(nlogn)` 的时间复杂度下运行。
     2. 缓存使用效率高：在执行哨兵划分操作时，系统可将整个子数组加载到缓存，因此访问元素的效率较高。而像堆排序这类算法需要跳跃式访问元素，从而缺乏这一特性。
     3. 复杂度的常数系数小：在上述三种算法中，快速排序的比较、赋值、交换等操作的总数量最少。这与插入排序比冒泡排序更快的原因类似。
- 代码示例：
```C++
/* 哨兵划分 */
int partition(vector<int> &nums, int left, int right){
  // 以 nums[left] 为基准
  int i = left, j = right;
  while(i < j){
    while(i < j && nums[j] >= nums[left]) j--;
    while(i < j && nums[i] <= nums[left]) i++;
    swap(nums[i], nums[j]);
  }
  swap(nums[i], nums[left]);
  // 返回此时基准数的索引
  return i;
}

/* 对于上述哨兵划分部分，需要注意的是： 
 * 比较的基准值的位置：选择左（右）端点作为基准值会影响后续 i++ 和 j-- 操作的顺序、最后 swap 操作的内容以及返回值
 * 即选取左端点时，需要先移动双指针中的右指针，在最后的 swap 操作内容是 i 和 左端点对应的值
 * 相反地，若选取右端时，需要先移动双指针中地左指针，在最后的 swap 操作内容是 j 和右端点对应的值
 * 如果 i 和 j 的操作顺序改变，导致本次排序完成并没有将正确的元素放在正确的位置（正常情况下每排序一次，都会得到一个排序完成的元素，它被放在按顺序排列的正确位置上）；如果在最后 swap 操作的内容不正确，也会导致同样的问题。
 */

 /* 上述哨兵划分可以换成： */
 int partition(vector<int> &nums, int left, int right){
  // 以 nums[right] 为基准点
  int i = left, j = right;
  while(i < j){
    while(i < j && nums[i] <= nums[right]) i++;
    while(i < j && nums[j] >= nums[right]) j--;
    swap(nums[i], nums[j]);
  }
  swap(nums[right], nums[j]);

  // j 位置是排序完成的点
  return j;
 }

/* 快速排序 */
void quickSort(vector<int> &nums, int left, int right){
  if(left >= right) return;

  int pivot = partition(nums, left, right);
  quickSort(nums, left, pivot - 1);
  quickSort(nums, pivot + 1, right);
}

/* 快排的另一种写法
 * 同样需要注意基准点的选取，还需注意递归时区间的选择
 */
void quickSort(vector<int> &nums, int left, int right){
  // 当左右端点相同时，无需排序直接返回
  if(left == right) return;
  // 选取右边端点作为基准点
  int partition = nums[right], i = left - 1, j = right + 1; // do while 形式，两边端点均向外扩充一个单位
  while(i < j){
    // 因为此时的判断条件中并没有 i 和 j 的比较
    // 因此，双指针的操作顺序可以交换
    do i++; while(nums[i] < partition); // 由于 partition 选取右端点的关系，i 的值不会超过右端点
    do j--; while(nums[j] > partition); // 由于 j 的初始位置为右端点的下一个位置，因此初始时 j 停在右端点；再此进入 while 循环时，由于前面的 swap 操作导致 partition 交换 j 的前面，因此 j 的取值一直操持在 nums[j] 的有效范围内
    if(i < j) swap(nums[i], nums[j]);
  }

  // 交换结束后，满足下述关系：
  // i 的左边部分值满足小于 i 位置值；但是 i 的右边部分不一定满足全大于 i 位置值
  // 相反地，j 的右边部分值满足大于 j 位置值；但是 j 的左边部分不一定满足全小于 j 位置值
  // 与上面哨兵写法比较可知：后者相当于是基准值取固定位置的值；而前者相当于是取固定值。后者再完成交换操作后，满足特定位置（即完成排序位置）的左右两边部分的大小关系；而前者由于在交换过程中 partition 值不变，但位置发生变化，同时结合 while 中的判断条件，能够得出：在 i 和 j 的一侧是满足特定大小关系的。

  // 因此可以将数组分为两部分：[left, i - 1] 和 [i, right]
  quickSort(nums, left, i - 1);
  quickSort(nums, i, right);
};

/* 当选择左边端点作为基础点时 */
void quickSort(vector<int> &nums, int left, int right){
  if(left == right) return;
  int partition = nums[left], i = left - 1, j = right + 1;
  while(i < j){
    do i++; while(nums[i] < partition);
    do j--; while(nums[j] > partition);
    if(i < j) swap(nums[i], nums[j]);
  }

  quickSort(nums, j + 1, right);
  quickSort(nums, left, j);
}
```

- 基准数优化

```C++
  if(m <= l && l <= r || r <= l && l <= m) return left;
  return right; 
}
```

- 尾递归优化
  为避免占用空间较多，可以仅对较短的子数组进行递归，从而**确保递归深度不超过 `logn`，从而将最差空间复杂度优化至 `logn`**。（1. 只有较短的子数组进入递归，因此递归深度超过 `logn`；2. 较长的子数组在同级的较短子数组通过递归完成排序后才进入循环（不是递归），此时该较长子数组又被拆分成两部分，因此较长的子数组不会进入递归流程，从而较少了栈空间的占用）。

  ```C++
      // 递归较短子数组

        quickSort(nums, left, pivot - 1);
        left = pivot + 1;
      }else{
        quickSort(nums, pivot + 1, right);
        right = pivot - 1;
  ```

## 归并排序
- 基本思想：归并排序（`merge sort`）是一种*基于分治策略的排序算法*，它分为*划分*、*合并*两个阶段。划分阶段（相当于递归阶段）：通过递归不断将数组**从中点处分开**，将长数组的排序问题转换为短数组排序问题；合并阶段（相当于回溯阶段）：当子数组长度为 1 时终止划分，开始合并。持续地将左右两个较短的有序数组合并为一个较长的有序数组，直至结束。可以发现，**归并排序和二叉树的后序遍历的递归循序是一致的**，后序遍历：先递归左子树，在递归右子树，最后处理根节点；归并排序：先递归左子数组，在递归右子数组，最后处理合并。
- 流程：
  1. 计算数组中点 `mid`，递归划分左子数组（区间 `[left, mid]`）和右子数组（区间`[mid + 1, right]`）；
  2. 递归执行步骤 1，直至子数组区间长度为 1 时终止；
  3. 合并阶段从底至顶地将左子数组和右子数组合并为一个有序数组。需要注意的是，长度为 1 的子数组开始合并，**合并阶段中的每个子数组都是有序的**。
- 特性：
  1. 时间复杂度：`O(nlogn)`。划分产生高度为 `logn` 的递归树，每层合并的总数操作数量为 `n`，因此总体时间复杂度为 `O(nlogn)`
  2. 非自适应排序
  3. 空间复杂度：`O(n)`。递归深度为 `O(logn)`，使用 `O(logn)` 大小的栈空间。合并操作需要借助辅助数组实现，使用 `O(n)` 大小的额外空间。
  4. 稳定排序：在合并过程中，相等元素的次序保持不变。
- 代码示例：
```C++

    if(nums[i] <= nums[j]){
      tmp[k++] = nums[i++];
    }else{
      tmp[k++] = nums[j++];
    }
  }

  将剩余元素复制到临时数组中

    tmp[k++] = nums[i++];
  }
  while(j <= right){
    tmp[k++] = nums[j++];
  }

  // 将临时数组中元素赋值回原来数组中
  for(k = 0; k <= tmp.size(); k++){
    nums[left + k] = tmp[k];
  }
}

void mergeSort(vector<int> &nums, int left, int right){
  if(left >= right) return;

  int mid = left + (left - right) / 2;
  mergeSort(nums, left, mid);
  mergeSort(nums, mid + 1, right);
  merge(nums, left, mid, right);
}
```
- 在链表排序上的应用：
  1. 对于链表，归并排序相较于其他排序算法具有显著优势，**可以将链表排序任务的空间复杂度优化至 `O(1)`**。
  2. 划分阶段：可以**使用迭代替代递归**来实现链表划分工作，从而省去递归使用的栈空间。
  3. 合并阶段：在链表中，节点增删操作仅需改变引用（指针）即可实现，因此合并阶段无需创建额外链表。
