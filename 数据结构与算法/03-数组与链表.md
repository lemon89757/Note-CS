## 列表（list）

表示元素的有序集合，支持元素访问、修改、添加、删除和遍历等操作，无须使用者考虑容量限制的问题。列表可以基于链表或数组实现。

* 链表：天然可以作为列表
* 数组：长度限制的列表，**通过动态数组实现列表**，许多编程语言中的标准库提供的列表是基于动态数组实现的，如Python中的 `list`、C++中的 `vector`、Java中的 `ArrayList`、C#中的 `List`等。有时将“列表”和“动态数组”视为同等的概念。

6. 方法 1：求全部元素的乘积，然后再除以对应位置的单个元素。此方法存在的问题是：未考虑除数是 0 的情况，即数组元素存在等于 0 的情况会导致该方法失效。
 方法 2：除自身以外数组的乘积可以看成两部分：元素自身左边、右边其他所有元素的乘积，而最终结果是这两部分的乘积。
 ```C++
class Solution{
public:
    vector<int> productExceptSelf(vector<int> &nums){
        vector<int> right(nums.size(), 0), left(nums.size(), 0);
        vector<int> res(nums.size(), 0);
        int product = 0;

        left[0] = 1;
        product = 1;
        for(int i = 0;i < nums.size(); i++){
            product *= nums[i];
            if(i + 1 < nums.size()) left[i + 1] = product;
        }

        right[nums.size() - 1] = 1;
        product = 1;
        for(int i = nums.size() - 1; i >= 0; i--){
            product *= nums[i];
            if(i - 1 >= 0) right[i - 1] = product;
        }

        for(int i = 0; i < nums.size(); i++){
            res[i] = left[i] * right[i];
        }
        
        return res;
    }
 }

/*  一种巧妙的方法，双指针 */
    vector<int> productExceptSelf(vector<int> &nums){
        vector<int> res(nums.size(), 1);
        int left = 0, right = nums.size() - 1;
        int productLeft = 1, productRight = 1;
        while(left < nums.size() && right >= 0){
            res[left] *= productLeft;
            res[right] *= productRight;
            productLeft *= nums[left++];
            productRight *= nums[right--];
        }
        return res;
    }
 ```
 7. 方法1：分情况。情况 1，最大值比 0 小，情况 2：最小值比 1 大，情况 3：应返回的值在最小值和最大值区间内，这时无法使用常数级别的额外空间来找到目标值，不管是用堆还是再次遍历来更新最小值，都无法满足时间或空间复杂度的要求。
**而事实上真正满足时间复杂度及空间复杂度的算法是不存在的，但是可以退而求其次，利用给定数组中的空间来存储一些状态**。
方法2：哈希表，因为对于一个长度为 `N` 的数组，缺失的第一个正数只有两种情况：1. 处于 `[1, N]` 闭区间内，2. 等于 `N + 1`。因此可以将给定的数组作为一个哈希表来存储数字的出现状况。对于数字 `n`，可以对给定数组索引为 `n - 1` 处进行标记，标记方式是：首先将数组中非正整数置为一个大于 `N` 的数，不妨置为 `N + 1`。再次遍历数组，将在区间 `[1, N]` 内的数 `x`，对数组中索引为 `x - 1` 处的元素加上负号作为标记。最后遍历数组，第一个不为负数的元素的对应索引减一即为返回值。
```C++
class Solution{
public:
    int firstMissingPositive(vector<int> &nums){
        for(int i = 0; i < nums.size(); i++){
            if(nums[i] <= 0) nums[i] = nums.size() + 1;
        }

        for(int i = 0; i < nums.size(); i++){
            int index = abs(nums[i]) - 1;
            if(abs(nums[i]) <= nums.size() && nums[index] > 0){
                nums[index] *= -1;
            }
        }

        for(int i = 0; i < nums.size(); i++){
            if(nums[i] > 0) return i + 1;

}
```

方法2：将数组中的元素进行交换，使得值为 `x` 的元素位于数组的 `x - 1` 索引处。
```C++
class Solution{
public:
    int firstMissingPositive(vector<int> &nums){
        for(int i = 0; i < nums.size(); i++){
            while(nums[i] > 0 && nums[i] <= nums.size() && nums[nums[i] - 1] != nums[i]){
                swap(nums[i], nums[nums[i] - 1]);
            }
        }

        for(int i = 0; i < nums.size(); i++){
            if(nums[i] != i + 1) return i + 1;
        }

        return nums.size() + 1;
    }
}
```
