## 列表（list）

表示元素的有序集合，支持元素访问、修改、添加、删除和遍历等操作，无须使用者考虑容量限制的问题。列表可以基于链表或数组实现。

### 实现

* 链表：天然可以作为列表
* 数组：长度限制的列表，**通过动态数组实现列表**，许多编程语言中的标准库提供的列表是基于动态数组实现的，如Python中的 `list`、C++中的 `vector`、Java中的 `ArrayList`、C#中的 `List`等。有时将“列表”和“动态数组”视为同等的概念。

6. 方法 1：求全部元素的乘积，然后再除以对应位置的单个元素。此方法存在的问题是：未考虑除数是 0 的情况，即数组元素存在等于 0 的情况会导致该方法失效。
 方法 2：除自身以外数组的乘积可以看成两部分：元素自身左边、右边其他所有元素的乘积，而最终结果是这两部分的乘积。
 ```C++
class Solution{
public:
    vector<int> productExceptSelf(vector<int> &nums){
        vector<int> right(nums.size(), 0), left(nums.size(), 0);
        vector<int> res(nums.size(), 0);
        int product = 0;

        left[0] = 1;
        product = 1;
        for(int i = 0;i < nums.size(); i++){
            product *= nums[i];
            if(i + 1 < nums.size()) left[i + 1] = product;
        }

        right[nums.size() - 1] = 1;
        product = 1;
        for(int i = nums.size() - 1; i >= 0; i--){
            product *= nums[i];
            if(i - 1 >= 0) right[i - 1] = product;
        }

        for(int i = 0; i < nums.size(); i++){
            res[i] = left[i] * right[i];
        }
        
        return res;
    }
 }

/*  一种巧妙的方法，双指针 */
    vector<int> productExceptSelf(vector<int> &nums){
        vector<int> res(nums.size(), 1);
        int left = 0, right = nums.size() - 1;
        int productLeft = 1, productRight = 1;
        while(left < nums.size() && right >= 0){
            res[left] *= productLeft;
            res[right] *= productRight;
            productLeft *= nums[left++];
            productRight *= nums[right--];
        }
        return res;
    }
 ```
