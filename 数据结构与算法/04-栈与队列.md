## 栈（Stack）

**先入后出**、**线性结构**

*`push(), pop(), peek()`: 入栈，出栈，查看栈顶元素

* 栈只能在栈顶添加或删除元素，而数组和链表都可以在任意位置添加和删除元素，因此**栈可以视为一种受限制的数组或链表**
* C++中的栈

```C++

// init

stack<int>stack;


// 入栈

stack.push(1);


// 访问栈顶

intnum=stack.top();


// 元素出栈

stack.pop();


// 获取栈的长度

intsize=stack.size();


// 判断是否为空

boolempty=stack.empty();

```

### 栈的实现

1. 链表实现

```C++

classStack{

    private:

        ListNode*head;

        intstackSize;

    public:

        Stack(){

            head=nullptr;

            size=0;

        }


        ~Stack(){

            // 遍历链表删除节点，释放节点

            freeMemoryLinkedList(head);

        }


        intsize(){

            returnstackSize;

        }


        boolisEmpty(){

            returnstackSize==0;

        }


        voidpush(intval){

            ListNode*node=newListNode(val);

            node->next=head;

            head=node;

            stackSize++;

        }


        intpop(){

            intres=head->val;

            ListNode*tmp=head;

            head=tmp.next;

            deletetmp;

            stackSize--;

            returnres;

        }


        inttop(){

            if(isEmpty()){

                throwout_of_range("Stack is empty");

            }

            returnhead->val;

        }


        vector<int> toVector(){

            ListNode*node=head;

            vector<int> res(size());

            for(inti=res.size() -1; i>=0 ; i--){

                res[i] =node->val;

                node=node->next;

            }

            returnres;

        }

}

```

2. 数组实现

```C++

classStack{

    private:

        vector<int> stack;

    public:

        intsize(){

            returnstack.size();

        }


        boolisEmpty(){

            returnstack.size() ==0;

        }


        voidpush(intval){

            stack.push_back(val);

        }


        intpop(){

            intnum=top();

            stack.pop_back();

            returnnum;

        }


        inttop(){

            if(isEmpty()){

                throwout_of_range("Stack is empty");

            }

            returnstack.back();

        }


        vector<int> toVector(){

            returnstack;

        }

}

```

### 实现对比

* 时间效率

当入栈与出栈操作的元素是基本数据类型时，例如 int 或 double：

    1. 基于数组实现的栈在触发扩容时效率会降低，但由于扩容是低频操作，因此平均效率更高

    2. 基于链表实现的栈可以提供更加稳定的效率表现

* 空间效率

  1. 基于数组实现的栈可能由于数组的容量超出实际需求而导致一定的空间浪费
  2. 基于链表实现的栈需要额外的空间来存储指针，因此链表节点占用的空间相对较大

### 典型应用

1. 浏览器中的前进与后退、软件中的撤销与反撤销：打开一个新的网页->入栈;后退到上一个网页->出栈；如果需要同时支持后退与前进，则需要两个栈来配合实现。
2. 程序内存管理：每次函数调用时，系统都会在栈顶添加一个栈帧，用于记录函数的上下文信息；在递归函数中，向下递推阶段会不断执行入栈操作，而向上回溯阶段则会不断执行出栈操作。

## 队列（Queue）

**先入先出**、**线性结构**

* C++中的队列

```C++

// init

queue<int>queue;


// 入队

queue.push(1);


// 访问队首元素

intnum=queue.front();


// 元素出队

queue.pop();


// 获取队列长度

intsize=queue.size();


// 判断是否为空

boolempty=queue.empty();

```

### 队列的实现

1. 链表实现

```C++

classQueue{

    private:

        ListNode*front, *rear; // 头节点、尾节点

        intqueueSize;

    public:

        Queue(){

            front=nullptr;

            rear=nullptr;

            queueSize=0;

        }


        ~Queue(){

            freeMemoryLinkedList(front);

        }


        intsize(){

            returnqueueSize;

        }


        boolisEmpty(){

            returnqueueSize==0;

        }


        voidpush(intval){

            ListNode*node=newListNode(val);

            if(front==nullptr){

                front=node;

                rear=node;

            }else{

                rear->next=node;

                rear=node;

            }

            queueSize++;

        }


        intpop(){

            intnum=peek();

          

            ListNode*temp=front;

            front=front->next;

            deletetemp;

            queueSize--;


            returnnum;

        }


        intpeek(){

            if(queueSize==0){

                throwout_of_range("Queue is empty");

            }

            returnfront->val;

        }


        vector<int> toVector(){

            ListNode*node=front;

            vector<int> res(size());

            for(inti=0; i<res.size(); i++){

                res[i] =node->val;

                node=node->next;

            }

        }

}

```

2. 数组实现

* 在数组中删除首元素的时间复杂度为 `O(n)`，这会导致出队操作效率较低；
* 避免这一问题的方法：使用一个变量 front 指向队首元素的索引，并维护一个变量 size 用于记录队列长度，于是可以定义 rear = front + size，这个公式计算出 rear 指向**队尾元素之后的下一个位置**。
* 数组中包含元素的有效区间为：[front, rear - 1]

1. 淘宝订单。购物者下单后，订单将加入队列中

* 各类待办事项。任何需要实现“先来后到”功能的场景
