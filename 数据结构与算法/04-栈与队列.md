## 栈（Stack）

**先入后出**、**线性结构**

* `push(), pop(), peek()`: 入栈，出栈，查看栈顶元素
* 栈只能在栈顶添加或删除元素，而数组和链表都可以在任意位置添加和删除元素，因此**栈可以视为一种受限制的数组或链表**
* C++中的栈

```C++
// init
stack<int> stack;
// 入栈
stack.push(1);
// 访问栈顶
int num = stack.top();
// 元素出栈
stack.pop();
// 获取栈的长度
int size = stack.size();
// 判断是否为空
bool empty = stack.empty();
```

### 栈的实现

1. 链表实现

```C++
class Stack{
    private:
        ListNode *head;
        int stackSize;
    public:
        Stack(){
            head = nullptr;
            stackSize = 0;
        }

        ~Stack(){
            // 遍历链表删除节点，释放节点
            freeMemoryLinkedList(head);
        }

        int size(){
            return stackSize;
        }

        bool isEmpty(){
            return stackSize == 0;
        }

        void push(int val){
            ListNode *node = new ListNode(val);
            node->next = head;
            head = node;
            stackSize++;
        }

        int pop(){
            int res = head->val;
            ListNode *tmp = head;
            head = tmp.next;
            delete tmp;
            stackSize--;
            return res;
        }

        int top(){
            if(isEmpty()){
                throw out_of_range("Stack is empty");
            }
            return head->val;
        }

        vector<int> toVector(){
            ListNode *node = head;
            vector<int> res(size());
            for(int i = res.size() -1; i >= 0 ; i--){
                res[i] = node->val;
                node = node->next;
            }
            return res;
        }
}
```

### 实现对比

* 时间效率

当入栈与出栈操作的元素是基本数据类型时，例如 int 或 double：

    1. 基于数组实现的栈在触发扩容时效率会降低，但由于扩容是低频操作，因此平均效率更高

    2. 基于链表实现的栈可以提供更加稳定的效率表现

* 空间效率

  1. 基于数组实现的栈可能由于数组的容量超出实际需求而导致一定的空间浪费
  2. 基于链表实现的栈需要额外的空间来存储指针，因此链表节点占用的空间相对较大

### 典型应用

1. 浏览器中的前进与后退、软件中的撤销与反撤销：打开一个新的网页->入栈;后退到上一个网页->出栈；**如果需要同时支持后退与前进，则需要两个栈来配合实现**。
2. 程序内存管理：每次函数调用时，系统都会在栈顶添加一个栈帧，用于记录函数的上下文信息；在递归函数中，向下递推阶段会不断执行入栈操作，而向上回溯阶段则会不断执行出栈操作。

### 单调栈
1. 单调栈用处：通常是一维数组，要寻找任一个元素的右边或左边第一个比自己大或小的元素的位置。
2. 相关问题见后面。

## 队列（Queue）

**先入先出**、**线性结构**

* C++中的队列

```C++
// init
queue<int> queue;
// 入队
queue.push(1);
// 访问队首元素
int num = queue.front();
// 元素出队
queue.pop();
// 获取队列长度
int size = queue.size();
// 判断是否为空
bool empty = queue.empty();
```

### 队列的实现

1. 链表实现

```C++
class Queue{
    private:
        ListNode *front, *rear; // 头节点、尾节点
        int queueSize;
    public:
        Queue(){
            front = nullptr;
            rear = nullptr;
            queueSize = 0;
        }

        ~Queue(){
            freeMemoryLinkedList(front);
        }


        int size(){
            return queueSize;
        }

        bool isEmpty(){
            return queueSize == 0;
        }

        void push(int val){
            ListNode *node = new ListNode(val);
            if(front == nullptr){
                front = node;
                rear = node;
            }else{
                rear->next = node;
                rear = node;
            }
            queueSize++;
        }

        int pop(){
            int num = peek();
            ListNode *temp = front;
            front = front->next;
            delete temp;
            queueSize--;
            return num;
        }

        int peek(){
            if(queueSize == 0){
                throw out_of_range("Queue is empty");
            }
            return front->val;
        }

        vector<int> toVector(){
            ListNode *node = front;
            vector<int> res(size());
            for(int i = 0; i < res.size(); i++){
                res[i] = node->val;
                node = node->next;
            }
        }
}
```

2. 数组实现

* 在数组中删除首元素的时间复杂度为 `O(n)`，这会导致出队操作效率较低；
* 避免这一问题的方法：
  1. 使用一个变量 front 指向队首元素的索引，并维护一个变量 size 用于记录队列长度，于是可以定义 rear = front + size，这个公式计算出 rear 指向**队尾元素之后的下一个位置**。
  2. **数组中包含元素的有效区间为**：[front, rear - 1]
  3. 入队操作：将输入元素赋值给 `rear` 索引处，并将 `size` 增加 1。
  4. 出队操作：只需将 `front` 增加 1，并将 `size` 减少 1。
* 上述方法存在的问题：
  在不断进行入队和出队过程中，`front` 和 `rear` 都在向右移动，当它们到达数组尾部时就无法继续移动了。为解决此问题，可以将数组视为首尾相接的“**环形数组**”。环形数组的周期性可以通过“**取余操作**”来实现。

```C++
class ArrayQueue{
    private:
        int *nums;  // 用于存储队列元素的数组，长度不可变，可以将其改为动态数组，引入扩容机制。
        int front;
        int queSize;
        int queCapacity;
    public:
        ArrayQueue(int capacity){
            nums = new int[capacity];
            queCapacity = capacity;
            front = queSize = 0;
        }

        ~ArrayQueue(){
            delete[] nums;
        }

        int capacity(){
            return queCapacity;
        }

        int size(){
            return queSize;
        }

        bool isEmpty(){
            return size() == 0;
        }

        void push(int num){
            if(queSize == queCapacity){
                // 当为动态数组时进行扩容
                count << "队列已满" << endl;
                return;
            }
            int rear = (front + queSize) % queCapacity;
            nums[rear] = num;
            queSize++;
        }

        int pop(){
            int num = peek();
            front = (front + 1) % capacity;
            queSize--;
            return num;
        }

        int peek(){
            if(isEmpty()){
                throw out_of_range("队列为空");
            }
            return nums[front];
        }

        vector<int> toVector(){
            vector<int> res(queSize);
            for(int i = 0; j = front; i < queSize; i++, j++){
                res[i] = nums[j % queCapacity];
            }
            return res;
        }
}
```

## 双向队列

在队列中，仅能**删除头部元素**或者在**尾部添加元素**。双向队列（double-ended queue）允许在头部和尾部执行元素的添加或删除，是自由度更高的队列。

* C++中的双向队列

```C++
// 初始化
deque<int> que;
// 入队
que.push_back(2);
que.push_front(4);
// 出队
que.pop_front();
que.pop_back();
// 访问
int front = que.front();
int back = que.back();
// 获取队列长度
int size = que.size();
// 判断是否为空
bool empty = que.empty();
```

### 双向队列的实现

1. 双向链表实现

```C++
struct DoublyListNode{
    int val;
    DoublyListNode* next;
    DoublyListNode* prev;
    DoublyListNode(int val) : val(val), prev(nullptr), next(nullptr){}
};

class LinkedListDeque{
    private:
        DoublyListNode *front, *rear;
        int queSize = 0;
    public:
        LinkedListDeque() : front(nullptr), rear(nullptr){}

        ~LinkedListDeque(){
            DoublyListNode* pre, *cur = front;
            while(cur != nullptr){
                pre = cur;
                cur = cur->next;
                delete pre;
            }
        }

        int size(){
            return queSize;
        }

        bool isEmpty(){
            return size() == 0;
        }

        void push(int num, bool isFront){
            DoulyListNode *node = new DoublyListNode(num);
            if(isEmpty()){
                front = rear = node;
            }else if(isFront){
                front->pre = node;
                node->next = front;
                front = node;
            }else{
                rear->next = node;
                node->pre = rear;
                rear = node;
            }
            queSize++;
        }

        void pushFirst(int num){
            push(num, true);
        }

        void pushLast(int num){
            push(num, false);
        }

        int pop(bool isFront){
            if(isEmpty()){
                throw out_of_range("队列为空");
            }
            int val;
            if(isFront){
                val = front->val;
                DoubleListNode *fNext = front->next;
                if(fNext != nullptr){
                    fNext->prev = nullptr;
                    front->next = nullptr;
                }
                delete front;
                front = fNext;
            }else{
                val = rear->val;
                DoubleListNode * rPrev = rear->prev;
                if(rPrev != nullptr){
                    rPrev->next = nullptr;
                    rear->prev = nullptr;
                }
                delete rear;
                rear = rPrev;
            }
            queSize--;
            return val;
        }

        int popFirst(){
            return pop(true);
        }

        int popLast(){
            return pop(false);
        }

        int peekFirst(){
            if(isEmpty()){
                throw out_of_range("双向队列为空");
            }
            return front->val;
        }

        int peekLast(){
            if(isEmpty()){
                throw out_of_range("双向队列为空");
            }
            return rear->val;
        }

        vector<int> toVector(){
            DoubleListNode *node = front;
            vector<int> res(size());
            for(int i = 0; i < res.sie(); i++){
                res[i] = node->val;
                node = node->next;
            }
            return res;
        }
}
```

2. 数组实现
   在队列的实现基础上，仅需增加“队首入队”和“队尾入队”的方法。

```C++
/* 基于环形数组实现的双向队列 */
class ArrayQueue{
    private:
        vector<int> nums;   // 通过动态数组保存
        int front;
        int queSize;
    public:
        ArrayQueue(int capacity){
            nums.resize(capacity);
            front = queSize =0;
        }

        int capacity(){
            // 不是返回 nums.capacity()
            return nums.size();
        }

        int size(){
            return queSize;
        }

        bool isEmpty(){
            return size() == 0;
        }

        int index(int i){
            // i 可能为负数，因此需要 i + capacity()
            return (i + capacity()) % capacity();
        }

        void pushFirst(int num){
            if(queSize == capacity()){
                cout << "双向队列已满" << endl;
                return;
            }
            front = index(front - 1);
            nums[front] = num;
            queSize++;
        }

        void pushLast(int num){
            if(queSize == capacity()){
                cout <<  "双向队列已满" << endl;
                return;
            }
            int rear = index(front + queSize);
            nums[rear] = num;
            queSize++;
        }

        int popFirst(){
            int num = peekFirst();
            front = index(front + 1);
            queSize--;
            return num;
        }

        int popLast(){
            int num = peekLast();
            queSize--;
            return num;
        }

        int peekFirst(){
            if(isEmpty()){
                throw out_of_range("双向队列为空");
            }
            return nums[front];
        }

        int peekLast(){
            if(isEmpty()){
                throw out_of_range("双向队列为空");
            }
            int last = index(front + queSize - 1);
            return nums[last];
        }

        vector<int> toVector(){
            vector<int> res(queSize);
            for(int i = 0, j = front; i < queSize; i++, j++){
                res[i] = nums[index(j)];
            }
            return res;
        }
}
```

### 典型应用

双向队列兼具栈与队列的逻辑，因此它可以实现这两者的所有应用场景，同时提供更高的自由度。例如，软件的“撤销”功能通常使用栈来实现：系统将每次更改 push 到栈中，然后通过 pop 实现撤销。然而考虑到系统资源限制，软件通常会限制撤销的步数（如限制50步）。当栈的长度超过50步时，软件需要在栈底执行删除操作。**但栈无法实现该功能，此时就需要使用双向队列来替代栈**。**“核销”的核心逻辑仍然遵循先入后出原则**。

7. 标准的单调栈问题，求取所有元素右边第一个比自己大的元素的位置。
```C++
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        // 栈定保存当前较小值的下标
        // 当前位置的值大于栈顶，则更新结果并将栈顶元素弹出
        // 当前位置的值小于等于栈顶，直接入栈
        stack<int> st;
        // 元素初始化为 0，没有更新的位置结果即为 0，表示右边没有比它大的值
        vector<int> res(temperatures.size(), 0);
        st.push(0);
        for(int i = 1; i < temperatures.size(); i++){
            while(!st.empty() && temperatures[st.top()] < temperatures[i]){
                res[st.top()] = i - st.top();
                st.pop();
            }
            st.push(i);
        }
        return res;
    }
};
```
8. 相当于是上述问题的改版，可以首先通过单调栈记录每个元素右边第一个比自己大的元素，这些内容保存在哈希表中，最后遍历 `nums1` 从哈希表中取出对应的元素即可。
```C++
class Solution {
public:
    vector<int> nextGreaterElement(vector<int>& nums1, vector<int>& nums2) {
        // 数组中没有重复元素，通过哈希表保存每个元素的第一个比自己大的元素的下标
        // 哈希表中 key 为元素值，value 为比自己大的元素
        unordered_map<int, int> mp;
        // 栈中保存元素的下标，栈顶为之前的较小值
        stack<int> st;
        st.push(0);
        for(int i = 1; i < nums2.size(); i++){
            while(!st.empty() && nums2[st.top()] < nums2[i]){
                mp.insert({nums2[st.top()], nums2[i]});
                st.pop();
            }
            st.push(i);
        }

        vector<int> res(nums1.size(), - 1);
        for(int i = 0; i < nums1.size(); i++){
            auto it = mp.find(nums1[i]);
            if(it != mp.end()) res[i] = it->second;
        }
        
        return res;
    }
};
```
9. 在问题：“下一个更大元素I” 的基础上，增加前置条件：数组为循环数组，要求每个元素的下一个更大元素。基本解法与“下一个更大元素I”相同，只需要改变一下遍历的过程即可：当要处理循环数组时，遍历两边数组，从而可以使最后一个元素的下一次元素为第一个元素。
```C++
class Solution {
public:
    vector<int> nextGreaterElements(vector<int>& nums) {
        vector<int> res(nums.size(), -1);
        stack<int> st;
        for(int i = 0; i < 2 * nums.size(); i++){
            while(!st.empty() && nums[st.top()] < nums[i % nums.size()]){
                res[st.top()] = nums[i % nums.size()];
                st.pop();
            }
            st.push(i % nums.size());
        }
        return res;
    }
};
```
